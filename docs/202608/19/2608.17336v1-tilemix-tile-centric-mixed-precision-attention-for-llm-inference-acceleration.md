## 摘要
长上下文预填充在大型语言模型（LLM）中会引发大量的计算和内存流量，因为密集自注意力会计算二次方的查询-键分数。现有方法要么使用统一的低精度路径，要么选择 token 交互，将硬件对齐分数瓦片上的空间精度路由排除在融合密集注意力之外。我们引入了 TileMix，一种以瓦片为中心的精度路由内核，它将数值精度作为融合密集注意力中分数瓦片组上的可执行空间决策。TileMix 将注意力矩阵划分为硬件对齐的分数瓦片，将路由决策打包为紧凑的位掩码，并通过 FP16 或 INT8 分数计算分派每个瓦片组，同时两条路径共享在线 softmax 状态。可扩展的精度分组使每个路由位能够管理多个相邻的键瓦片，在长上下文中保持硬件对齐的计算瓦片和紧凑的元数据。通过路由所有合法的瓦片组，TileMix 保持了密集的 token 连接性，无需训练，并支持分组查询注意力、可变长度批次和 INT8 键/值缓存。在 LLaMA、Qwen 和 Vicuna 上的 LongEval、LV-Eval 和 A100 预填充基准测试中，TileMix 恢复了在统一 INT8 下丢失的长上下文质量，并提高了预填充吞吐量（优于 FP16），在模型家族中产生了可控的精度-效率前沿。实现可在 https://github.com/HanzhiZhang-Ulrica/TileMix 获取。

## Abstract
Long-context prefill in large language models (LLMs) incurs substantial computation and memory traffic because dense self-attention computes quadratic query-key scores. Existing methods either use a uniform low-precision path or select token interactions, leaving spatial precision routing over hardware-aligned score tiles outside fused dense attention. We introduce TileMix, a tile-centric precision-routing kernel that makes numerical precision an executable spatial decision over score-tile groups within fused dense attention. TileMix partitions the attention matrix into hardware-aligned score tiles, packs routing decisions into compact bitmasks, and dispatches each tile group through FP16 or INT8 score computation while both paths update a shared online-softmax state. Scalable precision grouping lets each routing bit govern multiple adjacent key tiles, preserving hardware-aligned compute tiles and compact metadata at long contexts. By routing all legal tile groups, TileMix preserves dense token connectivity, requires no training, and supports grouped-query attention, variable-length batches, and INT8 key/value caches. Across LongEval, LV-Eval, and A100 prefill benchmarks on LLaMA, Qwen, and Vicuna, TileMix recovers long-context quality lost under uniform INT8 and improves prefill throughput over FP16, yielding a controllable accuracy-efficiency frontier across model families. The implementation is available at https://github.com/HanzhiZhang-Ulrica/TileMix.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：大型语言模型（LLM）在长上下文预填充阶段，密集自注意力需要计算 L×L 的查询-键分数矩阵，带来 O(L²) 的计算复杂度和大量 HBM 内存流量，成为长文档处理的主要瓶颈。
- **现有方法的不足**：
  - **低精度量化**（如 INT8）通常对整个注意力调用或阶段采用统一精度路径，无法在硬件对齐的分数瓦片（score tile）级别进行空间精度分配。
  - **稀疏注意力**通过剪枝 token 交互降低计算量，但改变了注意力图的连通性，可能损失关键信息。
  - **IO 感知的融合注意力**（如 FlashAttention）虽以瓦片为单位调度数据和计算，但分数计算仍为统一精度。
- **本文核心含义**：TileMix 将“数值精度”本身作为一种可执行的空间决策，在融合稠密注意力内部，对不同分数瓦片组动态选择 FP16 或 INT8 计算路径，既保留完整的注意力图（不引入稀疏性），又通过混合精度实现加速，填补了“瓦片级精度路由”这一空白。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：以硬件对齐的二维分数瓦片（BLOCK_M × BLOCK_N）为基本单元，在 FlashAttention 风格的流式执行框架内，为每个瓦片组分配 FP16 或 INT8 算术路径；两组路径共享同一份在线 softmax 状态（running max、normalizer、输出累加器）。
- **关键机制**：
  1. **瓦片化精度路由**：注意力矩阵划分为硬件对齐的分数瓦片；每个瓦片组的路由决策由二进制位表示（1=INT8，0=FP16）。
  2. **紧凑位掩码编码**：每个 KV 头与查询瓦片行的路由决策打包为一个 64 位整数；内循环通过一次移位-与操作（`(b >> gj) & 1`）实现常数时间路由查找，元数据规模为 O(H_k·T_m)。
  3. **可扩展精度分组**：通过分组因子 g，让一个路由位控制 g 个相邻键瓦片（BLOCK_mask_N = g·BLOCK_N），在长上下文下保持路由词表不超过 64 位且计算瓦片不改变。
  4. **共享状态异质分数执行**：
     - FP16 路径：`Q_m K_n^T / √d`。
     - INT8 路径：块级量化 Q、K → Q8、K8（对称 INT8，absmax 缩放，块大小 128×d 和 64×d），INT8 MMA 得到 INT32 累加，再乘以块尺度并除以 `√d` 进入 FP16 分数域。
     - 两条路径的分数统一后，共同更新在线 softmax 的 running max 与 normalizer，输出累加器保持在 FP16。
  5. **支持 GQA、变长批处理与 INT8 KV 缓存**：查询头映射到共享 KV 头，路由词复用；使用 prefix-sum 元数据支持变长序列；INT8 KV 缓存将 K8 用于 INT8 分数计算，V8 在片内转回 FP16 参与 PV。
  6. **量化策略**：主要采用“quantize-once”模式，在注意力调用前一次性生成 Q8、K8 及其尺度，所有 INT8 路由瓦片复用；也有“fused on-the-fly”模式在片内即时量化，以及独立的 INT8 KV 缓存接口。
- **路由策略来源**：采用静态、数据无关的结构化模板，包括 One（全 INT8）、Zero（全 FP16）、Band、Global、Row-Random、Aligned Sparse、BigBird、Sparse Transformer（SpTrans）等；这些模板仅决定算术路径，不改变注意力连通性。

## 6. 主要结论与发现

- 均匀 INT8 注意力（`One`）在长上下文检索和 QA 中通常明显低于 FP16，说明统一低精度路径过于粗糙。
- TileMix 混合路由配置能在保持稠密连接的同时，显著恢复均匀 INT8 损失的质量，多数情况下优于稀疏基线和 SageAttention，部分配置（如 SpTrans 在 factrecall_en 16k）甚至超过 FP16。
- 效率方面：TileMix 在 A100 上比 FlashAttention 显著提升预填充吞吐量（例如 LLaMA 3.2 3B 在 4k tokens 时 SpTrans75 达到 31.80 K tokens/s，FlashAttention 为 14.33 K tokens/s），接近或超过均匀 INT8 的 `One` 配置。

- 混合精度路由提供了可控的精度-效率前沿：覆盖率 25%~75% 提供了灵活的权衡旋钮，布局选择则影响不同任务上的质量保持能力。
