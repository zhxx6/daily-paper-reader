## 摘要
我们加速了一类基于Hessian任意Kronecker因子化近似来指导几何信息的神经网络量化算法。GPTQ风格的自适应舍入通常使用源自输入激活的单侧信息。双侧Kronecker因子化Hessian近似还能捕获输出坐标之间的相关性，但直接在向量化权重域中应用GPTQ计算代价高昂。基于BoA和YAQA使用的双侧自适应舍入公式，我们引入了BaKron，一种结合反对角并行与递归分治构造的高效求解器。对于m×n权重矩阵，BaKron使用O(m+n)个顺序步骤，同时将总工作量从O(m^2 n^2)减少到O(mn(m+n))。因此，它在利用更丰富曲率信息的同时，达到了与GPTQ相同的三次方规模。此外，BaKron在基础量化器和Hessian估计器方面都是模块化的。我们还提供了实用基准测试，考虑了BaKron可调用的一系列Hessian，找到了一种计算这些Hessian的高效技术，并对算法进行了实验评估。

## Abstract
We accelerate a family of algorithms for neural network quantization whose geometry is informed by any Kronecker-factored approximation of the Hessian. GPTQ-style adaptive rounding typically uses one-sided information derived from input activations. Two-sided Kronecker-factored Hessian approximations can additionally capture correlations across output coordinates, but applying GPTQ directly in the vectorized weight domain is computationally expensive. Building on the two-sided adaptive-rounding formulation used by BoA and YAQA, we introduce BaKron, an efficient solver that combines anti-diagonal parallelism with a recursive divide-and-conquer construction. For an $m\times n$ weight matrix, BaKron uses $O(m+n)$ sequential steps while reducing the total work from $O(m^2n^2)$ to $O(mn(m+n))$. Thus, it matches the cubic scaling of GPTQ while exploiting richer curvature information. Moreover, BaKron is modular with respect to both the base quantizer and the Hessian estimator. We also provide practical benchmarks, consider a range of Hessians that BaKron can be called with, find an efficient technique to compute these Hessians, and evaluate the algorithm experimentally.

# BaKron：利用Kronecker因子化Hessian的高效量化 —— 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：神经网络后训练量化（PTQ）旨在将训练好的模型权重从高精度转换为低精度，同时尽量保持模型精度。单个线性层 `W ∈ R^{m×n}` 的量化通常独立进行，但逐元素简单舍入（RTN）效果不佳，需要考虑网络几何信息。
- **已有方法**：GPTQ/OPTQ 使用输入激活的Gram矩阵 `XX^T` 作为几何信息，其对应的Hessian近似为 `H ≈ XX^T ⊗ I_m`，即“单侧”Hessian——只考虑输入特征相关性，忽略输出特征间相关性。
- **问题与挑战**：自然扩展是使用“双侧”Kronecker因子化Hessian `H ≈ A ⊗ B`（A对应输入侧，B对应输出侧），可捕获输出坐标间的相关性。BoA 和 YAQA 已使用这种形式，但计算效率低下：
  - BoA（Kim et al. 2024）：需 `O(mn)` 顺序步骤，总工作量 `O(m^2 n^2)`。
  - YAQA（Tseng et al. 2025）：并行化改进至 `O(m+n)` 顺序步骤，但总工作量仍为 `O(m^2 n^2)`。
- **本文目标**：提出新算法 **BaKron**，在保持 `O(m+n)` 顺序步骤的同时，将总工作量降至 `O(mn(m+n))`，与GPTQ的立方复杂度匹配，同时利用更丰富的双侧曲率信息。

## 2. 方法论

### 2.1 核心思想

- **BaKron-naive（算法2）**：将GPTQ直接应用于向量化权重域，对 `vec(W)` 使用Hessian `H = A ⊗ B`，通过Cholesky分解与Kronecker积的兼容性，将GPTQ的更新规则转化为矩阵形式。但需要 `mn` 个顺序步骤，计算代价高。
- **BaKron-antidiagonal（算法3）**：利用更新传播的偏序性质——某个条目 `(i,j)` 的舍入误差只会影响其右下方向（`i'≥i, j'≥j`）的条目，因此同一反对角线上的条目可以并行处理。将内层循环批量化为矩阵乘法，顺序步骤降至 `O(m+n)`，但总工作量仍为 `O(m^2 n^2)`（因每步矩阵乘法代价高）。
- **BaKron-recursive（算法5）**：采用递归分治策略，先处理矩阵左上部分，将误差传播到右下部分，再递归处理右下部分。单侧GPTQ中该技术不改变复杂度，但在二维矩阵情况下可将总工作量降至 `O(mn(m+n))`。
- **BaKron（算法6）**：将反对角并行与递归分治结合——在“反对角维度”上进行递归（先处理前半反对角线，传播误差到后半，再处理后部分），同时保持每步的并行性。最终实现：
  - 顺序步骤：`O(m+n)`
  - 总工作量：`O(mn(m+n))`

### 2.2 关键技术细节

- **符号与约定**：使用列主序向量化 `vec(W)`，Kronecker积满足 `(A⊗B)vec(W) = vec(BWA^T)`。Cholesky分解可分解于Kronecker积。
- **算法等价性**：定理3.2证明四种算法（naive、antidiagonal、recursive、BaKron）在精确算术下产生相同输出。证明基于：单个矩阵乘法可等价于一组外积更新的批量执行；低三角因子保证误差只沿“右下”方向传播；反对角线内条目互不影响。
- **复杂度分析**（表1）：

| 算法 | 几何信息 | 顺序步骤 | 总工作量 |
|------|---------|---------|---------|
| GPTQ | 单侧 | `n` | `mn²` |
| BaKron-naive（≈BoA） | 双侧 | `mn` | `m²n²` |
| BaKron-antidiagonal（≈YAQA） | 双侧 | `m+n` | `m²n²` |
| BaKron-recursive | 双侧 | `mn` | `mn(m+n)` |
| **BaKron** | **双侧** | **m+n** | **mn(m+n)** |

- **误差界**：通过GPTQ的误差界推导出BaKron的误差界：`||L(B)(V-W)(L(A))^T||_F^2 ≤ (1/4) tr(A)·tr(B)`，比GPTQ的 `(1/4) tr(A)·m` 更灵活，当 `tr(B)` 较小时可得到更紧的界。

### 2.3 Hessian近似方案

论文考虑了两种损失选择与两种Kronecker因子化方式的组合：

- **损失选择**：
  - **全局损失**：模型Fisher信息矩阵 `H_W = E[aa^T ⊗ gg^T]`，其中 `g = ∇_b L`，需要反向传播。
  - **局部损失**：基于单个模块（如注意力、MLP）的局部损失，无需反向传播。BoA风格注意力Hessian：`H_WQ = XX^T ⊗ KK^T` 等；本文新推导了MLP（GLU结构）的局部Hessian：`H_Wup = E[xx^T ⊗ (gg^T ⊙ W_down^T W_down)]` 等。
  
- **因子化方式**：
  - **K-FAC风格**：独立性假设，`H ≈ E[aa^T] ⊗ E[bb^T]`。
  - **Shampoo风格**：通过功率迭代求最优Kronecker近似，基于Van Loan–Pitsianis重排算子。单次迭代（初始化 `A=I,B=I`）给出 `A ≈ E[tr(b^Tb)·aa^T]`，`B ≈ E[tr(a^Ta)·bb^T]`。

### 2.4 高效计算反向传播Hessian

- **问题**：计算全局Hessian需要反向传播。朴素逐层反向传播需 `O(ℓ²)` 计算；YAQA式单次反向传播同时累积所有层Hessian需要 `O(ℓ)` 内存，对大型模型不现实。
- **本文递归方法**：将层列表递归二分，在中间层保存激活和梯度激活（边界矩阵），逐层递归处理。计算复杂度 `O(ℓ log ℓ)`，内存 `O(log ℓ)`，且保存的是激活而非Hessian，内存占用更可控。
- **实际意义**：与YAQA相比，虽然渐近内存常数不如理论对比显示的那样悬殊（因为Hessian比激活更紧凑），但关键是**加速器本地内存**需求大幅降低：YAQA需将全部Hessian驻留加速器，而本文方法只需在CPU与加速器间流式传输边界激活，可隐藏传输延迟。对Llama-3-8B，加速器驻留内存从几个模型大小降至单层规模。

## 6. 主要结论与发现

- **计算效率**：BaKron将双侧Kronecker因子化Hessian量化的总工作量从 `O(m^2 n^2)` 降至 `O(mn(m+n))`，顺序步骤 `O(m+n)`，与GPTQ复杂度匹配。Benchmark显示BaKron比之前的BaKron-antidiagonal（YAQA）快3.7×（小矩阵）到60×（大矩阵）。
- **端到端可行性**：由于核心算法不再主导总时间，端到端量化成本主要取决于Hessian累积和校准数据传播，与GPTQ相当。BaKron-naive在大型模型上完全不可行（Llama-3-8B需超过4天），而BaKron使其实用化。
- **量化质量**：
  - BaKron-Backprop-Shampoo 在多数模型上取得比GPTQ更低的Wikitext2困惑度（如Llama-3-8B：11.94 vs 53.47；Qwen3-8B：11.94 vs 14.58），但并非所有模型一致（如Qwen3-1.7B上其PPL 20.26优于GPTQ 35.97，但KFAC变体失败）。
  - 局部Hessian变体（MlpLocal、FullyLocal）性能与GPTQ接近或有小幅提升。
  - 没有单一变体在所有指标上全面最优；不同模型和任务上最优变体不同。
- **通用性**：BaKron对基础量化器和Hessian估计器模块化，可灵活搭配多种Hessian。
