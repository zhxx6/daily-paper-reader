## 摘要
低秩适配（LoRA）的混合专家（MoE）变体将每个标记路由到固定数量的专家 $k$。标记在模型对其不确定程度上各不相同，因此单一的 $k$ 会在简单标记上过度开销，而在困难标记上服务不足。我们观察到路由器的输出分布本身就是逐标记的不确定性信号：峰值质量表示置信度，而平坦分布表示模糊性。我们引入了CARE（专家置信度自适应路由），它以核方式接纳专家。专家按路由器权重递减顺序激活，直到其累积质量达到阈值，当已接纳的专家意见不一致时，会进行小幅扩展。预算恒温器校准阈值，使得活跃专家的平均数量匹配任意目标。CARE是一种即插即用、单次前向传播的规则，无需额外参数。在LLaMA-3.1-8B和Qwen2.5-7B上的八个常识基准以及数学、代码和知识任务中，CARE在匹配计算量下优于固定的top-k MoE-LoRA，并在激活更少专家的情况下匹配固定的k=4基线。相同的置信度和分歧信号也改进了分布外检测，优于MSP、熵和多遍代理。我们通过核保真度、预算最优性和对分歧的认知解读来支持该设计，并发布代码。

## Abstract
Mixture-of-Experts (MoE) variants of Low-Rank Adaptation (LoRA) route every token to a fixed number of experts $k$. Tokens differ in how uncertain the model is about them, so a single k over-spends on easy tokens and under-serves hard ones. We observe that the router's output distribution is already a per-token uncertainty signal: peaked mass indicates confidence, while a flat distribution indicates ambiguity. We introduce CARE (Confidence-Adaptive Routing of Experts), which admits experts in a nucleus fashion. Experts are activated in decreasing router weight until their cumulative mass reaches a threshold, with a small extension when the admitted experts disagree. A budget thermostat calibrates the threshold so that the average number of active experts matches any target. CARE is a drop-in, single-forward-pass rule with no extra parameters. Across eight commonsense benchmarks on LLaMA-3.1-8B and Qwen2.5-7B, as well as math, code, and knowledge tasks, CARE improves over fixed top-k MoE-LoRA at matched compute and matches the fixed-k=4 baseline while activating fewer experts. The same confidence and disagreement signals also improve out-of-distribution detection over MSP, entropy, and multi-pass proxies. We support the design with nucleus fidelity, budget optimality, and an epistemic reading of disagreement, and we release code.

# 论文总结：CARE——面向混合专家LoRA的置信度自适应路由

## 1. 核心问题与研究动机（背景与整体含义）

- **背景**：MoE（Mixture-of-Experts）变体的 LoRA（Low-Rank Adaptation）是参数高效微调的主流方法。现有的 MoE-LoRA 方法（如 LoRAMoE、MixLoRA、FlyLoRA、DynMoLE 等）均沿用稀疏 MoE 的固定 top-k 路由设计：**每个 token 无论难易都激活固定数量 k 个专家**。
- **核心问题**：固定 k 忽略了 token 之间的难度差异。简单 token（如功能词、无歧义的续写）只需少量专家即可处理，却被过度分配计算；困难或模糊的 token 需要更多专家，却得不到足够资源。这种"一刀切"策略在计算效率和模型效果上均有损失。
- **关键观察**：路由器 softmax 后输出的分布 p 本身就是天然的逐 token 不确定性信号——分布尖峰（peaked）表示模型对选哪个专家很有信心（置信度高）；分布平坦（flat）表示 token 具有模糊性（不确定性高）。与此同时，已选专家在输出空间上的分歧（disagreement）则可以补充捕捉"路由器自信但专家意见不统一"这种认知不确定性。
- **整体含义**：本文提出 CARE（Confidence-Adaptive Routing of Experts），利用上述两种信号动态决定每个 token 激活的专家数量，将计算预算从"容易"的 token 重新分配到"困难"的 token 上，从而在相同平均计算量下提升精度、在相同精度下节省计算，并且顺带获得免费的 OOD（分布外）检测得分。

## 2. 方法：CARE

### 2.1 核心思想

- 将固定的 k 替换为逐 token 动态的 k(h)，由路由器分布的集中度（confidence/aleatoric）和已选专家输出的分歧度（disagreement/epistemic）联合决定。
- 不改变训练目标、不增加参数、不需要额外前向传播或后验采样，即插即用地替换原 MoE-LoRA 的 top-k 门控。

### 2.2 两个不确定性信号

1. **置信度（aleatoric）**：路由器分布的集中程度——p(1)（top-1 质量）、p(1) − p(2)（margin）、归一化熵 H(p)、累积质量 Ck(p)。分布越尖峰，说明该 token 需要的专家越少；分布越平坦，说明越需要更多专家。
2. **分歧度（epistemic）**：对已选专家集合 S，定义尺度无关的分歧测度：
   - D(h; S) = 各坐标加权方差之和 / (∥e∥² + ε)。
   - D 高表示已选专家输出不一致，token 存在路由器"看不到"的歧义；此时继续增加专家是值得的。

### 2.3 核式专家接纳（Nucleus Expert Admission）

- 给定阈值 τ ∈ (0,1)，CARE 按路由权重降序激活专家，直到累积质量首次达到阈值：
  - kν(h; τ) = min { k : Ck(p) ≥ τ }
- 随后施加**认知分歧扩展**：若已选专家分歧超过阈值 δ，则最多追加 γ 个专家：
  - k(h) = clip( kν + ⌈γρ⌉, k_min, k_max )
  - 其中 ρ = max(0, (D−δ)/(1−δ)) 衡量分歧超出 δ 的程度，决定扩展量。
- 最终激活 top-k(h) 个专家，并按与 Eq.(1) 相同的方式加权融合。

### 2.4 预算恒温器（Budget Thermostat）

- 由于 kν(h; τ) 对每个 token 都关于 τ 单调不减，因此平均专家数 k̄(τ) 也关于 τ 单调不减。
- 通过一次二分搜索，即可在小型保留集上找到满足目标平均预算 B 的全局阈值 τ*：τ* = {τ : k̄(τ) = B}。
- 该阈值只需校准一次，测试时复用；由此保证 CARE 的平均激活专家数与 fixed-k 基线一致，从而在匹配 FLOPs 的条件下作公平对比。

### 2.5 不确定性读出（Uncertainty Read-out）

- 将路由熵与专家分歧加权融合，得到序列级不确定性得分：
  - u(x) = (1 − w)·H(p) + w·D(h; S)，默认 w = 0.5。
- u(x) 可直接用于 OOD 检测或选择性预测（abstention），无需任何额外计算。

### 2.6 成本

- 仅需 O(N log N) 的排序和 O(|S|d) 的分歧计算；单次前向传播、零新增参数。相比集成/贝叶斯方法的多遍推理成本极低。

### 2.7 理论支撑（四个性质）

- **命题1（核保真度）**：截断误差 ∥Δ − ΔS∥ ≤ (1−τ)·max_i ∥ei(h)∥，即核质量 τ 直接控制适配器输出的近似误差。
- **命题2（置信度排序）**：若正确率关于 top-1 质量 p(1) 单调，则按 p(1) 阈值化是最优选择分类器，达到最优风险-覆盖率曲线。
- **命题3（预算最优性）**：在凹性假设下，贪心分配等于单阈值规则；Eq.(5) 的恒温器实现了预算约束下的最优分配。
- **命题4（分歧即认知不确定性）**：D(h; S) 等价于（归一化的）集成预测方差，专家完全一致时为 0。

## 6. 主要结论与发现

- CARE 在**匹配计算量**下显著优于固定 top-k 的 MoE-LoRA：例如 LLaMA-3.1-8B 常识任务平均精度 86.5%（较最强基线 FlyLoRA 的 86.0% 提高 +0.5 个百分点）；数学/代码/知识任务平均 48.8%（较 FlyLoRA 47.9% 提高 +0.9 个百分点）。
- 在**匹配精度**下激活专家数量减少 12%：达到 fixed-k=4 的精度仅需平均 3.5 个专家。
- 在**精度-计算前沿**上，CARE 处处支配固定 top-k 前沿，中预算区间优势最大。
- OOD 检测方面：CARE 以单次前向达到 AUROC 0.668，优于单次 MSP/熵（约 0.640~0.651）乃至多遍 MC-dropout/深度集成代理（约 0.636~0.638），同时 ECE 保持可比（0.186 vs 0.175 量级）。
- 消融表明：**核式置信度信号主要带来精度增益**（47.9→53.7 中的大部分），**分歧信号主要带来 OOD 检测增益**（0.640→0.668），两者互补。
- 分布漂移下更鲁棒（shift 分割上 53.1% vs fixed-k 的 50.3%，计算量相同）。

## 7. 方法优点

- **即插即用**：不改变训练目标、不增加参数、不增加前向次数；仅替换门控规则即可用于任何输出路由器分布的 MoE-LoRA。
- **计算可控**：单一阈值 τ* 即可在精度-计算前沿上任意选择工作点。
- **不确定性免费**：同一前向传播同时得到路由决策和 UQ 分数，与集成/贝叶斯方法相比开销极低。
- **理论支撑扎实**：核保真度界、最优选择性分类、预算最优分配、分歧的集成方差解释，四个命题给了方法一个清晰的机理闭环。
- **机制透明**：通过机制分析（图4）直接展示了"聚度→正确率"、"难度→专家数"、"分歧→边际增益"三个因果链。
- **在匹配计算量的前提下取得正增益**，实验设计具有公平性意识。

## 8. 不足与局限

- **路由器质量依赖**：若路由器退化（近均匀或完全 one-hot），两种信号失效，CARE 退化为近常数 k，既不帮助也不损害（论文已诚实指出）。
- **工程适配问题**：自适应 k 与静态批处理和负载均衡不兼容，生产内核需要 kmax 封顶与 padding 等改造（论文讨论但未实现）。
- **UQ 评估范围有限**：仅做了分类式 ECE 和 OOD-AUROC，未验证自由生成场景下的语义不确定性。
- **OOD 场景偏弱**：所谓 OOD 是同域"更难"的移位，不是真正跨域分布外数据，因此对 OOD 检测能力的结论外推需谨慎。
- **多遍基线公平性存疑**：MC-dropout 和深度集成以"代理"身份参与对比，可能未经过充分调参或未针对任务优化，削弱了对比的公平性。
- **未见跨 backbone 大规模验证**：仅在 7B~8B 规模的两个模型上测试，未覆盖更大模型或其他架构族的可迁移性。
- **阈值与超参敏感**：虽然设计了恒温器，但 γ、δ、w、k_max 等仍需凭经验选取；论文提供了敏感性分析，但没有给出自动选择这些超参的机制。
- **绝对增益有限**：相对基线的提升在 0.5~0.9 个百分点之间，实际部署收益取决于具体场景；论文也承认收益大小与骨干网络、路由器质量、领域混合有关。
