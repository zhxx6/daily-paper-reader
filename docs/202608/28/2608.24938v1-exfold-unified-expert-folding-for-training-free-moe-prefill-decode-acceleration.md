## 摘要
混合专家（MoE）模型通过稀疏专家激活在保持每个令牌计算量有界的同时扩展容量以实现强质量。然而，低延迟MoE服务日益具有挑战性，因为它跨越两个瓶颈根本不同的推理阶段：预填充阶段以令牌级专家计算为主，而解码阶段受批级激活专家集的内存流量限制。然而，现有的免训练加速方法仅优化单一资源代理，要么优化每个令牌执行的专家，要么优化批次激活的专家，并且要么丢弃被排除专家的贡献，要么仅隐式近似。在本文中，我们提出ExFold，一个统一的免训练专家折叠框架，用于联合加速MoE预填充和解码。ExFold将预填充和解码均视为一个有预算的输出近似问题：仅执行阶段特定的受限专家集，同时使用校准的标量投影器将预算外专家的贡献投影到保留专家上。受许多专家输出方向对齐但幅度不同的观察启发，ExFold在未标记数据上校准成对标量投影器矩阵，并在推理时使用它将排除的专家贡献折叠进保留专家中。在此视角下，预填充加速变为令牌级Top-K折叠，解码加速变为批级专家池折叠。两个阶段仅在保留专家的选择方式上不同，而被排除的贡献通过一个共享折叠机制恢复。我们将ExFold作为即插即用插件在vLLM中实现，配以轻量级专家折叠CUDA内核，实现了高达1.41倍的TTFT和2.45倍的TPOT加速，同时保留了约99%的原始平均质量。

## Abstract
Mixture-of-Experts (MoE) models scale capacity for strong quality while keeping per-token compute bounded through sparse expert activation. Yet low-latency MoE serving is increasingly challenging, because it spans two inference phases with fundamentally different bottlenecks: prefill is dominated by token-wise expert computation, whereas decode is constrained by memory traffic from the batch-wise activated expert set. However, existing training-free acceleration methods optimize only a single resource proxy, either the experts each token executes or the experts a batch activates, and either discard the excluded experts' contribution or leave it only implicitly approximated. In this paper, we propose ExFold, a unified training-free expert-folding framework for jointly accelerating MoE prefill and decode. ExFold casts both prefill and decode as one budgeted output-approximation problem: execute only a phase-specific constrained expert set while projecting the contribution of budget-excluded experts onto retained experts using calibrated scalar projectors. Motivated by the observation that many expert outputs are directionally aligned but differ in magnitude, ExFold calibrates a pairwise scalar-projector matrix on unlabeled data and uses it at inference time to fold excluded expert contributions into retained experts. Under this view, prefill acceleration becomes token-level Top-K folding, and decode acceleration becomes batch-level expert-pool folding. The two phases differ only in how retained experts are selected, while excluded contributions are recovered by one shared folding mechanism. We implement ExFold as a plug-and-play plugin in vLLM, with a lightweight expert-folding CUDA kernel, delivering up to 1.41x TTFT and 2.45x TPOT speedups while retaining about 99% of the original average quality.

  - **预填充（Prefill）**：受 token 级专家计算量（FLOPs）约束，瓶颈在于每个 token 执行的专家数（Top-K）；
  - **解码（Decode）**：受内存带宽约束，瓶颈在于批次级别上激活的专家集合大小（batch-wise expert union）。
- **现状问题**：现有免训练加速方法只针对单一资源代理做优化——要么优化 token 级专家数（如 Dynamic-MoE、MoDES、MC-MoE），要么优化批级专家集（如 REAP、SERE、Lynx），且对**被裁剪/被排除专家的贡献**要么直接丢弃、要么静态合并固化、要么仅隐式近似，从未显式重建其贡献。

- **核心主张**：两阶段真正的区别只在于“保留哪些专家”（token 级 Top-K vs. 批次级专家池），而被排除贡献的恢复可以通过**同一套共享折叠机制**完成。

## 2. 方法论

### 核心思想
- **观察 1（设计基础）**：无论 prefill 还是 decode，被排除专家的残余贡献形式都是相同的 αe(xi)·Ee(xi)，因此两阶段共享同一个“输出恢复”目标。
- **观察 2（关键实证）**：MoE 中许多专家输出在方向上高度对齐（归一化后相似度显著提升），但幅度差异很大（同一层内 L2 范数 max/min 常超过 3 倍）。因此，一个**成对的标量投影器**（directed scalar projector）就足以纠正源专家和目标专家的幅度失配，不需要复杂的向量级重建。

### 关键公式与流程
1. **统一目标（式 5）**：对同一层内的一批 token，最小化近似输出与实际 MoE 输出的 L2 距离，同时满足阶段特定的预算约束（prefill 约束每 token 保留专家数，decode 约束每批保留专家数）。
2. **离线校准**（训练免费）：
   - 在未标记语料上收集共路由的源-目标专家输出对（ui = Es(xi)，vi = Et(xi)）；
   - 按源输出范数加权，求解加权岭回归（式 7-8）得到**成对标量投影矩阵 S**，并存储**投影损失矩阵 L**（式 9，用于推理时选择最小损失目标）。
   - 只做一次前向，无需标签、梯度或模型更新。
3. **阶段特定选择**：
   - **Prefill（式 10）**：对每个 token，按“路由权重 × 输出范数估计”的贡献幅度排序，保留 Top-Kpre 专家；
   - **Decode（式 11）**：对当前批次，按所有 token 聚合的贡献幅度排序，从批次激活专家并集中保留至多 D 个专家。
4. **最小损失转移（式 12）**：每个被排除的源专家选择保留集合中投影损失最小的目标专家。
5. **折叠操作**：
   - **Prefill（式 13）**：在路由元数据层面将被排除专家的权重按标量系数合并到目标专家权重上，之后仅执行 Kpre 个专家；
   - **Decode（式 14）**：将被排除专家的路由条目原位重映射到目标专家，并缩放权重。
   - 两种操作都只修改路由元数据（router metadata），**不改变专家参数、不改变原始路由器**，与现有 fused MoE kernel 兼容。
6. **实现**：作为 vLLM 的即插即用插件，配 Triton/CUDA 专家折叠内核，开销极低。

## 6. 主要结论与发现

- **Prefill 加速**：P4 预算下，ExFold 平均质量 69.26，优于直接 Top-4（66.64）~2.6 分，与原始模型持平或略优；GLM 上保留 97.2% 质量。
- **Decode 加速**：D32 预算下，Qwen3 平均质量仅比原始模型低 0.07 分；SERE-K2、REAP-D32 等基线的质量损失显著更大。
- **联合加速**：直接 Top-4 对两阶段同时压缩时平均质量跌至 56.17；ExFold P4+D64 保持 68.50，证明共享折叠机制避免了两个独立丢弃误差的叠加。
- **DeepSeek-V4-Flash（256 专家）**：P3+D128 保留 99.32% 原始平均质量；P3+D64 保留 97.68%，在极端预算下仍远优于直接 K=3（88.17%）。
- **效率收益**：在线 TTFT 最高加速 1.41 倍，TPOT 最高 2.45 倍（QPS=8），离线吞吐最高提升 1.20~1.29 倍；DeepSeek-V4 上在饱和吞吐时 D64 比原模型输出吞吐提升 1.29 倍。
- **标量投影器有效性**：成对标量投影器在质量-开销权衡上全面优于全局/层标量、对角投影和低秩投影；校准语料域不敏感（各域平均分差距 ≤1.9 分），说明 ExFold 学习的是专家输出几何结构而非任务特征。

## 7. 优点

- **统一框架**：将 prefill 和 decode 两种不同瓶颈的加速问题统一为一个输出近似问题，共享同一折叠机制，概念简洁、理论自洽。
- **训练免费、即插即用**：只需一次离线前向校准，不改变专家参数、不改变路由器、不更新模型权重；仅修改路由元数据，与现有 vLLM 的 fused MoE 内核、调度和并行优化天然正交。
- **标量折叠极其轻量**：一个标量系数直接折入路由权重，在线 Kernel 零额外向量变换开销（O(B·K) 级路由表操作）。
- **设计动机扎实**：以专家输出“方向对齐 + 幅度分离”的实证观察为出发点，解释了为何简单相似度重路由不足、为何标量投影足够。
- **实验系统全面**：跨 5 种 MoE 架构（含 284B 级 256 专家模型）、10+ 评测基准、3 组消融、在线/离线多视角效率分析，且有可复现代码和校准矩阵开源。
- **质量保持显著优于同预算基线**：在同等专家预算下，ExFold 常常比其他免训练方法高出数个百分点。

## 8. 不足与局限

- **校准数据规模偏小**：30B 级模型仅用 32 条序列（1~4K tokens）校准；虽然论文证明语料域不敏感，但未研究校准集规模对投影器质量的敏感性（无 scale-ablation）。
- **DeepSeek-V4 评估存在泄漏风险**：校准集包含 8 条 IFEval/IFBench 的输入，虽有明确披露且无标签/答案，但并非严格 held-out，读者需谨慎解读该模型的“零样本”表述。
- **基准采样不一致**：不同模型 AIME 采样数不同（32 vs 8）、GLM 的 MMLU-Pro 用 490 题子集而非全量，跨模型分数不完全可比。
- **效率实验覆盖面有限**：仅在 H800 上、单一请求长度/并发配置下测量，缺少 A100/H100、更长序列、更多并发等生产场景验证；TPOT 的在线数据只报告了 QPS≤12 的区间。
- **异常机制可能引入隐藏复杂度**：DeepSeek-V4 中加入了置信度感知的 fallback（系数 cs 回退到原始 Top-3 路由），这一机制未被消融，无法确定其对最终质量贡献多大。
- **联合加速场景仍有上限**：当预算极紧时（如 P4+D32），QMEN3 平均质量开始下滑（67.10 vs 69.04），说明折叠也不能无限补偿信息损失，论文对“理论上限”讨论不足。
- **未考虑与 KV cache 优化、投机解码等其他推理优化技术的组合效果**，对生产端“叠满 buff”的实际收益未知。
