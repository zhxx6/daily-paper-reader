## 摘要
本文针对Gemma-3-1B提出了一种逐层位分配方法，将问题表述为在退化预算约束（允许的生成质量损失水平）下的性能最大化（延迟降低）。这种方法不同于文献中使用的耗时且耗费资源的均匀层量化方法（如GPTQ或AWQ），也不同于没有已验证性能加速效果的分层分配方法（如MixLLM或TorchAO）。我们应用了先前工作SA-PTQ得到的层敏感性profile，在TensorRT-LLM中使用激活直通模式。每一层的精度根据先前步骤引入的分组（5+5、10+10、all26）逐块独立确定，区分FFN、Attention和lm_head对整体加速的贡献。在RTX 5090上测量了13种W8A8变体的时钟速度。我们发现，对于FFN和lm_head，量化/反量化的时间成本通过整数运算的使用得到了补偿，而对于短上下文长度，Attention则相反：额外的量化步骤会降低执行速度。由于导出失败，我们提出了TensorRT-LLM的SmoothQuant手动实现，该实现是必要的，但无法用于lm_head。在同时考虑所有三个准则且退化最小的情况下，找到的最佳解决方案是FFN 5+5与lm_head，其延迟降低11.0%，质量损失可忽略不计（Top-1一致率98.90%，困惑度退化+0.85%）。在可接受的质量损失下，FFN all26+lm_head可实现高达19.1%的加速。我们建议进一步优化：INT8融合注意力核、KV缓存量化、使用FP8代替INT8以及类似于FFN的部分Attention量化。

## Abstract
This paper proposes a layer bit allocation method for Gemma-3-1B, formulating the problem as performance maximization (latency decrease) given a degradation budget constraint (allowable level of generation quality loss). This approach is different from time- and resource-consuming uniform layer quantization methods that are used in the literature (like GPTQ or AWQ) or allocation methods without proven performance-accelerating effect (like MixLLM or TorchAO). The layer sensitivity profile resulting from our prior work SA-PTQ is applied using the activation pass-through mode inside TensorRT-LLM. For each layer precision is determined individually in blocks, according to a grouping introduced in the prior step (5+5, 10+10, all26), differentiating the contribution of FFN, Attention, and lm_head to the overall speedup. The clock speed was measured for 13 W8A8 variants on an RTX 5090. We find that for FFN and lm_head the time cost of quantization/dequantization is compensated for by the use of integer arithmetic, while for short context lengths, the opposite holds true for Attention: an additional step of quantization slows execution down. We propose a manual implementation of SmoothQuant for TensorRT-LLM which was necessary due to export failures, unavailable for lm_head. The best solution found under joint consideration of all three criteria with minimal degradation was FFN 5+5 with lm_head, providing an 11.0% reduction in latency with negligible quality loss (98.90% Top-1 agreement, +0.85% perplexity degradation). With acceptable quality loss for FFN all26 + lm_head, a speedup up to 19.1% was found possible. We suggest further optimizations: fused attention kernels in INT8, KV-cache quantization, using FP8 instead of INT8 and partial Attention quantization analogous to FFN.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 基于上一工作中提出的 SA-PTQ（Sensitivity-Aware Post-Training Quantization）层敏感性指标，量化每个层对权重量化的鲁棒性。
- 采用**分组逐层位宽分配**，根据敏感性选择可以安全量化的层（FFN、Attention、lm_head），其余层保持 FP16。
- 在 TensorRT-LLM 中使用激活直通/量化-反量化（Q/DQ）模式，将 INT8 计算绑定到指定层，并实测各配置的端到端吞吐量。

### 关键量化方案
- 使用 **W8A8**（权重和激活均为 INT8）对称逐通道量化：
  - 量化步长：\( s_i = \frac{\max_j |W_{i,j}|}{2^{b-1}-1}, \quad b=8 \)
  - 量化权重：\( \tilde{W}_{i,j} = \text{round}(W_{i,j}/s_i) \cdot s_i \)
- 层分组形式：
  - **5+5**：量化第 0–4 层和第 21–25 层（共 10 层）的 FFN；
  - **10+10**：量化第 0–9 层和第 16–25 层（共 20 层）的 FFN；
  - **all26**：量化全部 26 层的 FFN。
- Attention 量化采用相同分组框架，对 Q/K/V/O 线性投影做 W8A8；lm_head 因与嵌入矩阵共享权重，采用手动 SmoothQuant 实现。
- SmoothQuant 校准：
  - 平滑系数：\( \delta_j = \frac{\max_t |X_{t,j}|^\alpha}{\max_i |W_{i,j}|^{1-\alpha}} \)，其中 \(\alpha=0.5\)
  - 将激活除以 \(\delta_j\)，将权重乘以 \(\delta_j\)，使动态范围重新分布。
  - 激活按 token 动态量化；权重静态逐通道量化；最终 GEMM 在 INT8 域完成，再反量化回 FP16。
- 对于 lm_head（输出维度 262144），因 TensorRT-LLM 插件限制单次最多 65536 个输出通道，将权重按行拆分为 4 个块分别执行。

### 技术实现与工程细节
- 使用 TensorRT-LLM 1.2.1 构建推理引擎，ModelOpt 执行量化。
- 手动修复了 lm_head 量化导出失败问题：检查点导出时必须设置 `decoder_type='gemma3'`，且校准算法必须显式指定为 `{"method": "smoothquant", "alpha": 0.5}`。
- 通过 NVIDIA Nsight Systems / Nsight Compute 对 kernel 级耗时和 DRAM 吞吐进行分析。

## 6. 论文的主要结论与发现

- **FFN 量化稳定有效**：
  - 5+5：393.5 tok/s，约 1.031×；
  - 10+10：408.6 tok/s，约 1.075×；
  - all26：414.98 tok/s，约 1.090×。
- **Attention 量化在短上下文中无加速，反而略微变慢**：
  - attn_ffn all26 为 407.28 tok/s，低于 FFN all26 的 414.98 tok/s；
  - 原因是 TensorRT-LLM 的 masked_multihead_attention 核心依然在 FP16 上运行，只有 Q/K/V/O 线性投影被 INT8 加速；GQA 架构下这些投影矩阵较小，收益不足以抵消 Q/DQ 开销。
- **lm_head 量化独立有效**：
  - lm_head-only：407.49 tok/s，约 1.071×，质量基本保持（Top-1 一致性 98.90%，困惑度 +0.85%）。
- **最优组合**：
  - **FFN 5+5 + lm_head**：422.14 tok/s，约 1.110×，且质量保持良好，是综合速度/质量的最佳配置；
  - **FFN all26 + lm_head**：453.27 tok/s，约 1.191×，速度最高但生成质量退化（出现循环重复）。
- **重要工程教训**：
  - INT8 收益不是由“数值精度是否允许”单独决定的，还取决于底层 kernel 是否真正使用 INT8 路径；
  - 非量化中间层（如 5+5 中未量化的中间层）可作为量化误差的“补偿器”，缓解量化误差传播。

## 8. 不足与局限

- **模型覆盖有限**：仅针对 Gemma-3-1B，结论未必适用于其他 sLLM 或大尺寸 LLM。
