## 摘要
大语言模型推理中的权重量化必须在自适应重建级别与足够规则以实现高效GPU执行的表示之间取得平衡。均匀整数将每个组约束为线性网格。低位浮点格式使用固定的指数-尾数结构，而学习型码本以不规则解码和额外元数据为代价获得灵活性。我们提出了CubicQuant，一种参数化非均匀标量格式，它在保留密集整数码流的同时，在每个权重组内自适应调整重建级别。由两个形状参数和一个尺度指定的单调三次曲线将均匀间隔的幅度码映射到非均匀级别。该系列涵盖1-8位权重有效载荷，将对称均匀整数量化作为精确特例包含在内，对于有效载荷宽度B和组大小G，每权重的有效宽度为B + 64/G位。我们推导了在均匀、高斯和拉普拉斯分布下的总体失真，制定了连续和动态A8载体感知拟合目标，并描述了直接打包权重的GPU执行。对于G=128的有限组，每组分布有15,360个样本，相对于最优裁剪的四位均匀整数量化，W4 CubicQuant在均匀分布样本上的重建RMSE降低了3.90%，在高斯分布上降低了13.49%，在拉普拉斯分布上降低了28.14%。相对于枚举的最佳四位有限浮点格式，降幅分别为3.90%、9.44%和6.27%。初步H200内核测量显示存在随工作负载变化的交叉点：对于窄GEMV，模型dtype执行更快，而随着行数增长，动态A8变得有利。结果确立了该格式的表示优势和直接可执行性；下游模型质量和跨设备端到端性能仍是待评估的问题。

## Abstract
Weight quantization for large-language-model inference must balance adaptive reconstruction levels with representations regular enough for efficient GPU execution. Uniform integers constrain each group to a linear grid. Low-bit floating-point formats use a fixed exponent-mantissa structure, while learned codebooks gain flexibility at the cost of irregular decoding and additional metadata.   We introduce CubicQuant, a parametric non-uniform scalar format that preserves a dense integer code stream while adapting reconstruction levels within each weight group. A monotonic cubic curve, specified by two shape parameters and one scale, maps uniformly spaced magnitude codes to non-uniform levels. The family spans 1-8-bit weight payloads, contains symmetric uniform integer quantization as an exact special case, and has effective width B + 64/G bits per weight for payload width B and group size G. We derive population distortion under Uniform, Gaussian, and Laplace distributions, formulate continuous and Dynamic-A8-carrier-aware fitting objectives, and describe direct packed-weight GPU execution.   For finite groups of G=128 with 15,360 samples per distribution, W4 CubicQuant reduced reconstruction RMSE relative to optimally clipped four-bit uniform integer quantization by 3.90% on Uniform, 13.49% on Gaussian, and 28.14% on Laplace samples. Relative to the best enumerated four-bit finite floating-point format, the reductions were 3.90%, 9.44%, and 6.27%. Preliminary H200 kernel measurements show a workload-dependent crossover: model-dtype execution is faster for narrow GEMV, while Dynamic A8 becomes favorable as row count grows. The results establish the format's representational promise and direct executability; downstream model quality and cross-device end-to-end performance remain open evaluation questions.

## 1. 核心问题与研究动机

大语言模型（LLM）自回归推理需反复从GPU显存中读取大型权重矩阵，降低权重存储位宽可直接缓解容量和带宽压力。然而，低精度条件下的关键矛盾在于：

- **均匀整数（Uniform Integers）**：表示紧凑、算法规整，但每个组被限制在线性网格上，无法适配局部统计特性；
- **低比特浮点格式（Low-bit Floating-point）**：通过固定的指数-尾数结构重新分配级别，但动态范围模式固定、灵活性有限；
- **学习型码本（Learned Codebooks）**：所有级别均可自由适配，但解码路径不规则、元数据开销高，与GPU矩阵点积路径天然不匹配。

文中提出 **CubicQuant**，目标是在“固定网格”与“自由码本”之间寻找折中：保留标量整数码和规则的压缩位流，同时通过组内参数化的单调三次曲线自适应地调整重建级别位置，实现 1–8 位权重的直接GPU执行。

## 2. 方法论

### 2.1 核心思想

CubicQuant 将“有效载荷位流”与“值重建方式”解耦：比特流仍是规则、紧凑的整数码，但每个权重组的重建级别由两个形状参数和一个尺度参数共同决定，可在组内独立生成非均匀的非线性码本。

### 2.2 符号与码空间定义

- 设有效载荷位宽为 `B`（`B ∈ {2,…,8}`），定义 `M = 2^(B−1) − 1`，码值 `k ∈ {−M,…,0,…,M}`，共 `2^B − 1` 个有效值；
- 最负的二补码模式 `−2^(B−1)` 被保留并确定性解为零，从而获得精确零点并保持正负端点对称；
- W1 为独立的二进制情况，码为 `{−1, +1}`，无零码；
- 打包码按行优先逻辑顺序连续存储，非对齐位宽（W3、W5–W7）需处理跨字节解码逻辑。

### 2.3 参数化级别函数

归一化码幅 `t_k = |k|/M`，重建函数为：

```
q(t) = t [a + t (b + c t)]，其中 c = 1 − a − b
ŵ(k) = sign(k) · s · q(t_k)
```

- `s`：正的组尺度（FP32），决定端点幅度（`k = ±M` 映射到 `±s`）；
- `a`、`b`：存储的形状系数（FP16），控制内部级别的分布；
- 由于 `q(0) = 0`、`q(1) = 1`，零和端点精确成立；
- **单调性约束**：`q′(t) = a + 2bt + 3(1−a−b)t² > 0`（t∈[0,1]），保证级别不反转；
- **均匀整数是精确特例**：`a = 1, b = 0, c = 0` 时 `q(t) = t`。

### 2.4 元数据与有效宽度

每组（`[1, G]` 组形状）存储：
- `G·B` 位有效载荷比特
- 1 个 FP32 尺度 `s`
- 2 个 FP16 形状系数 `a`、`b`

每权重元数据开销为 `64/G` 位，有效存储宽度为：

```
B_eff = B + 64/G（位/权重）
```

### 2.5 失真分析与理论界

- 推导了在均匀、高斯、拉普拉斯三种参考分布下的**精确总体失真表达式**（基于小区间矩展开）；
- 建立了集合包含关系：`均匀整数 ⊆ Cubic族 ⊆ 自由对称码本`，因此：

```
D_LM(B) ≤ D_Cubic(B) ≤ D_INT(B)
```

- 定义“可恢复差距比例” `η_B = (D_INT − D_Cubic)/(D_INT − D_LM)`；
- 通过 Lloyd–Max 条件给出自由码本下界；枚举所有有限浮点指数/尾数划分，比较最佳浮点格式。

### 2.6 有限组拟合

- 每个有限权重组独立拟合 `(s, a, b)`，目标为组内原始域平方误差最小化；
- 有限组可产生比总体最优更低的期望重构误差（每一组都可自适应于局部样本波动）；
- 连续目标用于模型dtype路径；**Dynamic-A8载体感知目标**将级别的INT8投影（`round(127·q(t))/127`）纳入拟合，联合优化 `L_joint = (L_C + L_A8)/2`，支持同一份checkpoint同时服务两种执行路径。

### 2.7 GPU执行

- **核心原则**：重建与消费融合（fused decode-and-compute）——仅加载打包权重和元数据，在计算tile内生成临时操作数并立即用于点积，不物化全精度权重张量；
- **模型dtype路径**：FP16/BF16激活，重建连续Cubic级别，稠密tile用`tl.dot`，窄行GEMV用FP32乘加；
- **Dynamic-A8路径**：按行动态量化INT8激活，权重映射到有符号INT8载体（`r(k) = round(127·sign(k)·q(|k|/M))`），INT32累加后FP32组级缩放；
- **内核选择**：窄GEMV vs 稠密tile、native CUDA vs 通用Triton，由测量延迟作为 `(B, G, M, N, K)` 的函数确定。

## 6. 主要结论与发现

1. **表示能力**：
   - 均匀分布下，均匀整数网格已是总体最优，Cubic无总体优势；但拉普拉斯和高斯分布下，优化后的Cubic族在 W4–W8 恢复 INT-LM 差距的 **84.8%–96.1%（高斯）**和 **91.4%–96.9%（拉普拉斯）**；
   - W3 时 Cubic 的 `s, a, b` 三个自由度恰与三个正级别一一对应，可精确达到自由 Lloyd-Max 下界，这是由参数计数决定的，而非数值巧合；
   - 总体比较中，除 W2 持平外，Cubic 在高斯、拉普拉斯上均优于最佳有限浮点格式。

2. **有限组自适应**：
   - 每个有限组可以局部适配，因此即使均匀分布整体线性最优，有限组下 Cubic 仍可改善误差（W4 高于均匀整数 3.90%）；
   - W4 相对最优均匀整数的 NRMSE 降低：均匀 3.90%、高斯 13.49%、拉普拉斯 28.14%；相对最佳有限FP：3.90%、9.44%、6.27%。

3. **执行可行性**：
   - 存储压缩比（相对BF16）：G=256时从 W1 的 12.8× 到 W8 的 1.94×；
   - H200 上模型dtype与Dynamic A8存在随M增大的延迟交叉点：M=1时 A16 更快，M≥64时 A8 普遍占优（如 W8: A8 快至 4.46×）；
   - 持久化激活载体为负结果——带宽节省无法抵消同步/归约/写入开销，故动态A8限定为算子局部计算模式。

4. **格式属性**：
   - 有效宽度显式为 `B + 64/G` 位/权重；
   - 同一份 checkpoint 可

同一份 checkpoint 可同时服务连续模型dtype路径与 Dynamic-A8 载体路径，无需为两条执行路径分别保存不同形式的权重副本；
- 基于二补码整数码、确定性零值解引用与组内参数化重建，解码时无需查找表，可直接在 GPU 上以标量算术完成“解码—乘加”融合；
- W1 作为独立的二值特例处理，其码本只有 {−1, +1}，因此元数据开销、内核选择与量化策略均与多比特情形分开设计。

1. **缺乏端到端任务质量评估**：论文没有报告困惑度、通用推理基准（如 MMLU、GSM8K）、下游任务精度或长上下文稳定性。CubicQuant 的宣称收益仅限于数值重建误差与内核延迟，缺乏“最终用户指标”层面的验证。

3. **内核测量覆盖有限**：H200 实验仅覆盖 2 种形状、3 种位宽和 4 种 M 值，没有给出 W1–W8 的完整扫描，也没有覆盖更宽的批大小、更长上下文、多请求流水线或 KV 缓存受限场景。

4. **单卡、单架构验证**：所有实测在单块 H200 上进行，Blackwell、Ampere 等架构的表现完全依赖编译推断；未涉及多 GPU 张量并行、专家并行或预填充—解码分离流水线。

5. **激活路径不对称**：Dynamic-A8 只是将权重压缩到低比特，激活仍为 INT8；W1/激活低比特边界被报告为负结果，说明该方法没有真正解决“激活也低比特”时的系统瓶颈。

6. **组大小 G 的影响未系统探索**：有限组实验只测了 G=128；G 对元数据开销、拟合质量与内核效率的三方权衡缺乏系统扫描。

7. **缺乏与成熟生产量化方案的同台对比**：没有与 AWQ、GPTQ、QuIP# 或近期低比特格式（如 MXFP4、NormalFloat）在相同内核与任务条件下进行比较，无法评估相对工程价值。

---

## 8. 总结性评述

CubicQuant 的贡献在于提出了一类“结构化但可自适应”的码本家族：它通过三次多项式、两个形状系数和一个共享尺度，在保持标量整数码流、无查找表解码、GPU 原生点积路径的前提下，让每个权重组的重建级别能够偏离均匀网格。这一设计巧妙地将 Lloyd–Max 连续最优码本的“自由度”压缩为每组的三个连续参数，同时不破坏打包、解码与计算的规则性。理论结果表明，在重尾分布上它能恢复均匀整数与自由最优码本之间的大部分差距，且有限组拟合还能进一步利用局部样本波动；负结果（持久化激活失败）也如实呈现，增强了结论的可信度。

不过，从工程采用角度看，仍缺少端到端质量与多硬件部署证据。当前实证仅限于数值重建误差和单 GPU 微观内核延迟，能否在真实 LLM 推理中获得端到端加速与质量无损，仍需下游任务实验与完整推理引擎集成来验证。总体而言，CubicQuant 是一个概念清晰、理论支撑扎实、对 GPU 执行友好的量化编码方案，距离生产级结论仍有一段实证距离。
