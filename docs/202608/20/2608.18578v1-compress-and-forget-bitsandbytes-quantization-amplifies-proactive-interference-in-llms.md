## 摘要
前摄干扰（PI）是大语言模型中一种已记录在案的故障模式，在这种模式下，随着先前覆盖的累积，对反复覆盖的值的检索会退化，这反映了人类工作记忆中的经典现象。训练后量化（PTQ）现在是开放权重模型的默认部署路径，但其对此故障模式的影响尚未得到测试。我们评估了三种精度级别（FP16、INT8、INT4/NF4，通过 bitsandbytes），跨越三个架构不同的指令微调模型（Qwen2.5-7B-Instruct、Mistral-7B-Instruct-v0.3、Phi-3.5-mini-instruct），并保持检索任务固定。INT4 量化在每个模型的高干扰下显著降低了准确率（例如，Qwen 从 81.0% 降至 68.3%），这通过配对 McNemar 检验（$p \le 2.6 \times 10^{-6}$）和跨越所有干扰水平的混合效应回归得到证实；INT8 通常被认为是安全的，但在三个模型中的两个中也带来了较小但实际的损失。该效应特定于语义相似（词类型）干扰物，并在数字控制条件下反转符号，且在机制上与 INT4 下同键入侵错误的增加有关（从试验的 21.5% 增加到 24.6%，$p = 4.8 \times 10^{-7}$）。后续消融实验表明，该效应源于量化的 transformer 主干，而非输出投影层。这些结果表明，即使总体基准准确率看起来基本未受影响，bitsandbytes 4 位量化也会对依赖长、可更新、语义密集上下文的应用施加额外成本。我们在 https://github.com/ShayanShahrabi/compress-and-forget 发布了代码和经过分词器验证的词汇构建方法。

## Abstract
Proactive interference (PI) is a documented failure mode in large language models in which retrieval of a repeatedly overwritten value degrades as prior overwrites accumulate, mirroring a classical phenomenon in human working memory. Post-training quantization (PTQ) is now the default deployment path for open-weight models, yet its effect on this failure mode has not been tested. We evaluate three precision levels (FP16, INT8, INT4/NF4, via bitsandbytes) across three architecturally distinct instruction-tuned models (Qwen2.5-7B-Instruct, Mistral-7B-Instruct-v0.3, Phi-3.5-mini-instruct), holding the retrieval task fixed. INT4 quantization significantly reduces accuracy under high interference in every model (e.g., from 81.0% to 68.3% for Qwen), confirmed by paired McNemar's tests ($p \le 2.6 \times 10^{-6}$) and a mixed-effects regression spanning all interference levels; INT8, often assumed safe, also carries a smaller but real penalty in two of three models. The effect is specific to semantically similar (word-type) distractors and reverses sign under a numeric control condition, and is mechanistically linked to a rise in same-key intrusion errors under INT4 (from 21.5% to 24.6% of trials, $p = 4.8 \times 10^{-7}$). A follow-up ablation shows the effect originates in the quantized transformer backbone rather than the output projection layer. These results suggest that bitsandbytes 4-bit quantization can impose an additional cost on applications relying on long, updatable, semantically dense contexts, even when aggregate benchmark accuracy appears largely unaffected. We release our code and tokenizer-verified vocabulary construction method at https://github.com/ShayanShahrabi/compress-and-forget

- **Post-training quantization (PTQ)**：是开放权重模型部署的主流路径。bitsandbytes、GPTQ、AWQ 等通常只报告聚合指标（困惑度、MMLU 等），基本假设是 4-bit 量化“足够安全”。
- **核心研究问题**：量化的聚合指标稳健性是否能推广到干扰密集的检索场景？压缩权重是否会不成比例地恶化这一本已脆弱的认知能力？这两条研究线此前从未被连接。
- **整体含义**：该研究首次系统评估了 PTQ 对 PI 的影响。结果表明 4-bit 量化在高干扰语义检索任务中会造成显著且可复现的准确率损失，而这种损失完全被聚合指标“平均掉”。对依赖频繁更新、语义密集上下文的实际应用（多轮助手、偏好追踪、文档修订追踪）有重要的安全隐患。

## 2. 论文提出的方法论：核心思想、技术细节与流程

### 核心思想
在同一固定的检索任务上，仅改变量化精度（FP16 / INT8 / INT4），系统比较量化对模型抵抗 PI 能力的影响。关键设计在于使同一组试验在三种精度下**逐试验配对**，从而使用更高统计功效的配对检验。

### 关键技术与流程
- **任务设计（PI-LLM 范式）**：对同一主题的同一属性进行 k 次覆盖（干扰等级 k ∈ {1,2,4,8,16,32,64,96}），仅查询最终值，要求单字/单数字回答。
  - **语义条件（词类型）**：4 个属性（情绪、最喜欢的颜色、最喜欢的动物、职业），干扰项来自同一语义类别，可混淆性强。
  - **数字控制条件**：3 个属性（温度、股票价格、页数），干扰项为任意整数，语义混淆性最小。
- **分词器验证的词汇构建**：候选词必须经分词器验证为单 token（通过字符偏移映射直接检查真实模板中的 token 化结果），避免词频漂移和 token 长度漂移与干扰等级混杂。这一点对字节级 BPE（Qwen）和 SentencePiece（Mistral/Phi）两种分词器家族都稳健。

- **统计方法**（多层验证策略）：
  - **McNemar 配对检验**（主要检验）：利用逐 trial 配对性，仅使用不一致的 trial 对，功效远高于非配对检验。
  - **Fisher 精确检验（非配对）**与 **Mantel–Haenszel 池化检验**：作为更保守的交叉验证。
  - **混合效应逻辑回归**：`correct ~ quant_mode * log2(level) + (1|model) + (1|seed) + (1|attribute)`，使用**全部**干扰等级和试验数据，关键项是 INT4 × log2(水平) 交互项，并附加随机斜率的稳健性检验。
  - **错误分类**：所有错误被分类为“同键入侵”（答案精确匹配某个被覆盖的旧值）或“非匹配错误”。
  - **IES（干扰耐力评分）**：准确率 vs log2 干扰水平曲线的归一化 AUC，用于标准化汇总。

## 6. 论文的主要结论与发现

1. **INT4 显著加剧 PI 下的准确率崩溃**：在各自的关键高干扰水平，FP16→INT4 准确率显著下降（Qwen 81.0%→68.3% OR=20.0，p=4.1×10⁻¹⁰；Mistral 44.0%→37.4% OR=2.58；Phi 61.8%→54.0% OR=3.60）。所有 15/15 个种子比较方向一致。
2. **INT8 并非普遍安全**：配对检验发现 Mistral（OR=1.84, p=0.018）和 Phi（OR=2.50, p=0.004）存在真实但较小的 INT8 损失，非配对检验无法检测到这一点。整体图景是“平缓梯度”（FP16 ≥ INT8 ≥ INT4）而非“干净悬崖”。
3. **效果具有特异性**：在语义（词类型）干扰下 INT4 显著受损，而在数字控制条件下**符号反转**（混合模型 word: β=−0.046, p=5.7×10⁻⁸；numeric: β=+0.053, p<10⁻¹⁶），排除了“量化=通用噪声”的假设。
4. **机制为同键入侵增加**：99.8–99.9% 的错误是同键入侵（检索到旧值而非胡答）；INT4 使侵入率从 FP16 的 21.5% 显著上升至 24.6%（p=4.8×10⁻⁷），表明量化**特异性**增加了语义相似候选之间的混淆度。
5. **效果源于主干网络而非 lm head**：额外量化输出投影层在三个模型中均无显著附加影响（全部 p=1.0），lm head 贡献仅占总 FP16→INT4 差距的 0–2.5%。
6. **聚合指标掩盖问题**：总体准确率上 FP16 与 INT4 仅差 1–2 个百分点，但在具体高干扰条件下差距可达 10–13 个百分点。

## 7. 优点

- **严谨的配对实验设计**：全数据集验证了 trial 级配对零失配，使 McNemar 检验成为可能，并显著提升了统计功效——发现 INT8 效应是普通非配对检验无法检测的。
- **多层统计验证**：主要检验（配对）+ 保守交叉检验（非配对 Fisher/Mantel-Haenszel）+ 全数据混合效应模型 + 随机斜率稳健性检查，层层递进，说服力强。
- **具有机制深度的错误分析**：不仅有准确率数字，还通过重建确定性试验序列将每个错误分类为同键入侵或非匹配错误，直接观察到了量化增加混淆性的行为证据。
- **特异性控制良好**：语义 vs 数字双条件设计，加上 token 长度分层，排除了 tokenization 混淆，有力地论证了效果的语义特异性。
- **消融实验细致**：不仅定位了效应到主干网络，还诚实记录了库默认行为（lm head 未量化）的方法学陷阱，并加以修正。
- **方法学透明与可复现性强**：公开代码和数据，在单卡消费级 GPU 上完成，门槛低；特别详细记录了分词器验证词汇构建中的“坑”（偏移映射而非算术推理）。

## 8. 不足与局限

- **量化方法覆盖有限**：仅测了 bitsandbytes（LLM.int8() 和 NF4），未涵盖 GPTQ、AWQ、EXL2、HQQ 等校准式量化方法；也未涉及激活/缓存量化。NT4 的发现并不一定代表所有 4-bit 量化。
- **模型规模范围窄**：仅覆盖 3.8–7B 的开源模型，未测试更大模型（13B/70B 等），泛化性有待验证。
- **上下文长度有限**：prompt 最长仅几百 token，未覆盖 8k+ token 的长上下文场景；与现有长上下文检索研究 [13] 的交互方向未知。
- **机制证据为行为推断**：同键入侵和主干定位虽然是两条有力的行为学证据线，但未直接探查模型的表征内部（注意力模式、残差流精度等），机制解释仍是推测性的。
- **数字控制条件词汇非单 token**：虽然分层检验减轻了担忧，但与词类型池在过滤严格性上不对称，仍是一个遗留的设计瑕疵。
- **报告了未完全验证的细节**：IES 的词汇上限跨度处理方式被标注为“未独立验证”；Phi 的 INT8 数字条件出现未解释的非对称性（损失 5.49%）。
- **结果对统计检验选择敏感**：不同检验方法（配对 vs 非配对）会给出不同且显著不同的结论，说明效应量中等，实践上需要注意不要过度解读个别模型的极端 OR 值。

## 9. 结论与启示（对领域与应用的广泛含义）

- **对“量化安全性”基本假设的修正**：业界通常默认 4-bit PTQ 只带来“可接受的、均匀的”性能下降。本研究的核心结论直接挑战了这一假设——量化造成的退化不是均匀噪声，而是**特异性地**作用于语义混淆这一本就薄弱的认知环节。在干扰密集的任务剖面下，INT4 可以制造出聚合指标完全无法反映的 10–13 个百分点局部崩溃。因此，“聚合指标稳健”不能作为“任务行为稳健”的充分证据。
- **对部署实践的明确警示**：多轮助手（会话历史中反复修改偏好或约束）、偏好追踪系统、文档修订/版本追踪等场景，恰好是 PI 密集场景。对这些应用而言，模型在量化前应增加**任务级压力验证**（而非仅看 MMLU/困惑度）；若高干扰检索是核心链路，则应谨慎选择 4-bit 部署，或在量化后补充针对性缓解措施。各模型敏感度差异显著（Phi 在 k=8 即失效、Qwen 到 k=64 才显现），说明不能依据单个模型的安全结论外推至其他模型。
- **对评测方法论的启示**：平均准确率会掩盖难度依赖的故障剖面。本研究示范了“行为定向探针 + 分层难度剖面 + 配对统计检验”这一组合拳的效力——正是配对的 McNemar 检验发现了非配对检验无法察觉的 INT8 效应。这提示 LLM 评估领域应更多采用任务定向探针，并报告难度分层而非单一聚合分数。
- **对可解释性与机制研究的价值**：量化可被看作一种受控的“精度损伤”干预手段。本研究中 INT4 特异性增加同键入侵率的行为证据，为理解模型内部检索机制的精度需求提供了一个可复用的实验范式：通过人为降低权重精度，观察哪类认知任务最先崩溃，从而反推其对表征精度的依赖程度。

## 10. 未来研究方向与个人评价

**未来研究方向**：
- 将实验扩展到更多量化路线（GPTQ、AWQ、EXL2、HQQ 等校准式方法）以及激活/缓存量化，验证 INT4 效应是否为 bitsandbytes NF4 特有；
- 将模型规模提升至 13B/70B，并延长上下文（8k+ token），探究 PI 退化与长上下文检索失败之间的交互关系；
- 开展表征层面分析（注意力模式、残差流精度、隐藏状态余弦距离），将“同键入侵增加”由行为证据升级为机制证据；
- 探索缓解策略，例如对高干扰敏感层（或注意力头）做混合精度保留，或在推理时引入显式的“值覆盖标记”；
- 将本范式推广至其他记忆故障模式（后摄干扰、多值绑定、事实更新后的灾难性遗忘）。

**个人评价**：
该工作的选题敏锐且务实——它填补了量化评估与记忆可靠性研究之间一个真实且高风险的空白。实验设计在行为探针类研究中属于上乘：配对设计加多层统计验证是最大亮点，错误分类与消融实验则使结论超越了“准确率下降”的表面观察，具备机制指向性。局限同样明确：覆盖模型与量化方法范围偏窄、机制证据停留在行为层面、INT8 效应量中等且对检验方法敏感。总体而言，这篇论文的定位更接近一份**严谨的“警示性研究”**——它无法最终裁定 4-bit 量化的安全性，但足以迫使部署者在高干扰语义场景下重新审视量化默认值，并为后续机制研究和缓解工作提供了可复用的方法论基线。
