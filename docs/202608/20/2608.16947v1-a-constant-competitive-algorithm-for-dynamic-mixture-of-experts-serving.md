## 摘要
Huang、Lou和Xiao引入了动态混合专家服务，并为其整数原问题给出了一种O(sqrt(log k))竞争的随机算法，其中k是每个专家强制副本之外的副本GPU数量。他们的匹配下界适用于一个辅助对偶问题，使得原问题的阶仍然开放。我们证明对于任意数量的专家，随机原竞争比实际上是Theta(1)。上界将倒数最大服务成本归结为追逐具有覆盖行稀疏度为2的正体。一个有限切包络在常数因子内近似每个倒数外图，可累加的正重置将累积服务转化为移动，一个非扩张平衡投影去掉了正体算法的资源增强。将所得分数路径与懒惰阈值舍入结合，得到E[ALG] <= 10 C_PB OPT + (5 C_PB + 2) k + 16，其中C_PB是在资源增强为1且覆盖稀疏度为2时来自追逐正体的绝对常数。完整的归约、舍入组合以及量化的主定理在Lean 4中相对于两个引用源定理的精确形式接口进行了机器验证。确定性有理控制和新的独立重放伴随形式证明。

## Abstract
Huang, Lou, and Xiao introduced Dynamic Mixture-of-Experts Serving and gave an O(sqrt(log k))-competitive randomized algorithm for its integral primal problem, where k is the number of replica GPUs beyond the mandatory copy of each expert. Their matching lower barrier applies to an auxiliary dual and leaves the primal order open. We prove that the randomized primal competitive ratio is in fact Theta(1) for arbitrary numbers of experts. The upper bound reduces reciprocal-max service costs to chasing positive bodies with covering row sparsity two. A finite tangent envelope approximates each reciprocal epigraph within a constant factor, summable positive resets convert accumulated service into movement, and a nonexpansive balanced projection removes the positive-body algorithm's resource augmentation. Combining the resulting fractional path with Lazy Threshold Rounding gives   E[ALG] <= 10 C_PB OPT + (5 C_PB + 2) k + 16,   where C_PB is the absolute constant from Chasing Positive Bodies at resource augmentation one and covering sparsity two. The full reduction, rounding composition, and quantified main theorem are machine-checked in Lean 4 relative to exact formal interfaces for the two cited source theorems. Deterministic rational controls and a fresh independent replay accompany the formal proof.

**背景与动机**
- 混合专家（Mixture-of-Experts, MoE）模型在推理时，需要在多个专家之间动态分配 GPU 副本。当工作负载随时间变化时，系统必须决定每个专家分配多少副本 GPU，以平衡两个相互冲突的目标：一方面，迁移副本会产生切换成本（switching cost）；另一方面，副本不足会造成瓶颈延迟。

## 2. 论文提出的方法论

**核心思想**
- 将“倒数最大服务成本”问题归约为“追逐正体”（Chasing Positive Bodies）问题。具体地，将每个专家的服务成本函数 r/(1+u) 的外图（epigraph）用有限条切线做常数因子近似，再通过事件/重置机制将累计服务成本转化为追逐算法的位移，最后通过非扩张平衡投影消除资源增强，并利用 Lazy Threshold 舍入将分数解转为整数解。

**关键技术步骤**

1. **有限切线包络**：固定 workload 坐标 r ≥ 0 与增强分配 u ≥ 0，令 q = 1 + u，对 p ∈ {1, ..., 2k+1} 定义切线 L_{r,p}(u) = r(2p − q)/p²。引理 2 证明：
   - 对任意 p > 0，r/q − L_{r,p}(u) = r(q−p)²/(q p²) ≥ 0，即切线始终是下估计；
   - 当 0 ≤ u ≤ 2k 时，存在 p ∈ {1, ..., 2k+1} 使得 L_{r,p}(u) ≥ (3/4)·r/(1+u)。
   - 由此构建有限包络 H_r(u) = max_{1≤p≤2k+1} L_{r,p}(u)，满足 (3/4)·r/(1+u) ≤ H_r(u) ≤ r/(1+u)。
   - 由于不等式 s ≥ L_{r,p}(u) 可化为覆盖行 (p²/(r(2p−1)))·s + (1/(2p−1))·u ≥ 1，其支撑大小至多为 2，满足正体追逐定理要求的覆盖行稀疏度 d = 2。

2. **事件/重置归约**：
   - 使用增强坐标 (u₁, ..., u_m, s) ∈ R^{m+1}_{≥0}。
   - 收到请求 r_t 后，构造事件正体 E_t = {(u,s)：∑u_i ≤ k, s ≥ L_{r_{t,i},p}(u_i) ∀i,p}；
   - 在每轮动作后构造重置正体 R_t = {(u,s)：∑u_i ≤ k, s ≤ δ_t}，其中 δ_t = 2^{-t}（t ≥ 1），δ₀ = 0。几何衰减的正重置序列确保误差项求和有界（∑_{t≥1} δ_t = 1）。
   - 使用参数 ϵ = 1 的正体追逐算法，事件覆盖行精确满足，打包行右端可放宽 2 倍。

3. **非扩张平衡投影**：给定 ∑u_i ≤ 2k 的增强点，映射到精确预算分数分配：
   - ρ(u) = (k − (1/2)∑u_i)/m，x_i(u) = u_i/2 + ρ(u)。
   - 引理 4 证明该投影满足：x(u) ≥ 0、∑x_i(u) = k、x_i(u) ≥ u_i/2（即容量不减半）、且 1-Lipschitz（∥x(u)−x(v)∥₁ ≤ ∥u−v∥₁）。

4. **服务成本到运动的收费**：利用容量减半不等式、切线包络下界 (3/4)，以及事件/重置端点距离，得到：
   - ∑_t f_t(x(u_t)) ≤ (4/3)M + 16/3，其中 M 为正体追逐算法的总位移；
   - 路径移动满足 ∥x₁−x₀∥₁ + ∑_{t≥2}∥x_t−x_{t−1}∥₁ ≤ M + 2k。

5. **Lazy Threshold 舍入**：将分数路径在线转为整型路径，保证服务成本至多增大 3 倍、期望移动不增加。结合比较器路径的移动上界 M ≤ C_PB(k + 2·OPT)，最终得到：
   - **E[ALG] ≤ 10·C_PB·OPT + (5·C_PB + 2)k + 16**。

**形式化验证**：归约、舍入组合及主定理已在 Lean 4 中完整机器验证，仅依赖两个源定理（追逐正体定理与 Lazy Threshold 舍入引理）作为显式的源接口，不重新证明源定理本身。
