## 摘要
在边缘设备上部署大型语言模型（LLM）进行推理，由于严重的内存和带宽限制而充满挑战。尽管推测解码和混合专家（MoE）已被提出以提高推理效率，但简单地将它们组合往往会带来过多的验证开销和较差的专家复用，限制了它们在内存受限的边缘场景中的有效性。在这项工作中，我们提出了S2-MoE，一种用于边缘设备上MoE推理的高效自推测解码框架。S2-MoE通过路由感知的自适应推测扩展减少冗余验证，通过复用感知的专家门控提高验证效率，并通过共享上下文使草稿和目标执行对齐。在llama.cpp中实现，S2-MoE在边缘设备上的多种MoE模型和数据集上，相比标准的自回归解码实现了最高5.3倍（平均约2.0倍）的加速。代码可在https://github.com/angerybob/S2-MoE获取。

## Abstract
Deploying large language models (LLMs) for inference on edge devices is challenging due to severe memory and bandwidth constraints. While speculative decoding and Mixture-of-Experts (MoE) have been proposed to improve inference efficiency, naively combining them often incurs excessive verification overhead and poor expert reuse, limiting their effectiveness in memory-bound edge settings. In this work, we propose S2-MoE, an efficient self-speculative decoding framework for MoE inference on edge devices. S2-MoE reduces redundant verification through routing-aware adaptive speculative expansion, improves verification efficiency with reuse-aware expert gating, and aligns draft and target execution via shared context. Implemented in llama.cpp, S2-MoE achieves up to 5.3x speedup (about 2.0x on average) over standard autoregressive de?coding across diverse MoE models and datasets on edge devices.Code is available at https://github.com/angerybob/S2-MoE.

- **背景矛盾**：推测解码（Speculative Decoding, SD）通过草稿模型并行验证多个 token 来提高“输出密度”；MoE（Mixture-of-Experts）通过稀疏激活降低“参数密度”。两种技术看似互补，但简单结合在边缘场景下效果很差：
  - MoE 中草稿 token 可能激活不同的专家，导致并行验证时参数复用率低、验证成本高；

  - token 级别的置信度无法反映专家级别的验证成本；
  - 外部草稿模型难以与 MoE 目标模型良好对齐。
- **核心贡献**：提出 S2-MoE，一种面向边缘设备 MoE 推理的高效自推测解码框架，通过三项关键技术（路由感知自适应推测扩展、复用感知专家门控、上下文对齐自推测）同时提升草稿保真度、降低冗余验证、增强专家复用，在 llama.cpp 中完整实现并开源。
- **整体意义**：S2-MoE 是首个在真实边缘设备上系统解决“SD + MoE”组合低效问题的训练无关方案，证明了自推测解码在边缘 MoE 推断中的实用价值。

## 2. 论文提出的方法论

S2-MoE 由三个互补组件构成，目标是同时满足“高草稿保真度、低冗余验证、强参数复用”三个要求。

### 2.1 路由感知的自适应推测扩展（Routing-aware Adaptive Speculative Expansion）

- **动机**：MoE 中两个置信度相似的草稿候选可能因激活不同专家而产生截然不同的验证开销；仅靠置信度剪枝无法有效控制验证成本。
- **核心思想**：用“验证效用”（utility）来指导推测树的扩展，效用 = 预期收益 / 预期成本。
- **预期收益**：对草稿 token \(i\)，其前缀置信度 \(p_i = \prod_{j=1}^k p_{i,j}\) 是它能被接受的概率，期望收益 \(B_i = p_i \cdot T_{AR}\)，其中 \(T_{AR}\) 是目标模型单步自回归延迟。
- **路由感知成本估计**：边际验证成本为
  \[
  \Delta C_{\text{ver}}(i|S) = \left| E_i \setminus \bigcup_{j \in S} E_j \right| \cdot T_{\text{exp}}
  \]
  即新增专家数量乘以单专家验证延迟。该估计使用草稿阶段的路由信号（实验表明与目标路由高度相关），并通过离线 profiling 校准到硬件延迟（\(R^2=0.943\sim0.999\)，MAPE=0.8%–4.5%）。
- **扩展策略**：总成本 \(C_i = \Delta C_{\text{ver}}(i|S) + C_{\text{draft}}^i\)，效用 \(U_i = B_i / C_i\)。贪心地接受 \(U_i \ge 1\) 的候选，直到没有候选满足条件。相比固定宽度或置信度剪枝，它能兼顾接受概率和验证开销，避免高代价低质量分支。

### 2.2 复用感知的专家门控（Reuse-aware Expert Gating）

- **动机**：MoE 中相邻 token 常路由到不同专家，导致并行验证时专家参数复用率低、内存流量大。同时专家重要性高度倾斜，低分专家之间存在功能冗余。
- **核心步骤**：
  1. **跨 token 专家重要性聚合**：用 token 置信度 \(w_b\) 作为权重，聚合各 token 的专家 gating logits：
     \[
     g_e = \sum_{b \in B} w_b \cdot \ell_{b,e}
     \]
     高置信度 token 的专家偏好获得更大权重。
  2. **全局优选专家选择**：选择 TopCap 个全局优选专家 \(E^*\)，cap 不小于 top-\(k\)，保证原始 top-\(k\) 专家仍可被选择，限制偏置范围。
  3. **软路由偏置**：对每个 token 的 gating logits 施加加性偏置：
     \[
     \ell'_{b,e} = \ell_{b,e} + \lambda_b \cdot \mathbb{1}[e \in E^*]
     \]
     \(\lambda_b\) 与 token 的 top-1 与第 \(k+1\) 名专家得分差距成正比，使偏置主要作用于边界专家，保留强偏好专家的相对顺序。
- **实现**：基于轻量级融合 CUDA kernel，开销可忽略；偏置仅调整次要专家，质量影响有限（后文实验表明 PPL 变化极小）。

### 2.3 上下文对齐的自推测解码（Context-aligned Self-speculative Decoding）

- **动机**：自推测草稿若拥有独立上下文，误差会随解码步累积，导致草稿与目标分布逐步背离。
- **核心思想**：草稿与目标模型共享统一的 KV Cache。目标模型先处理 prompt 建立 KV；草稿直接读取共享上下文；草稿产生的 KV 更新被视为临时状态，验证前回滚，只提交被接受的 token。
- **效果**：草稿误差被限制在单次推测步内，不跨迭代累积（实验显示 KL 散度增长被显著抑制）。

## 6. 论文的主要结论与发现

- S2-MoE 在 Jetson Orin 上取得 **1.3×–5.3×** 加速，在 RTX 4090 上取得 **1.2×–2.9×** 加速（相对 AR），平均约 2.0×。
- 朴素自推测基线（ES、LS）在 MoE 上往往不如 AR，甚至更慢（尤其紧内存下），说明低专家复用和冗余验证是核心障碍。
- S2-MoE 无需训练，却能稳定超越需要额外训练的 EAGLE3 和策略性的 Cascade，且提升幅度随内存收紧而增大（内存越紧优势越明显）。
- 上下文对齐显著提高接受率（最高 +79%），证明共享 KV Cache 是自推测在 MoE 上的关键基础。
- 路由感知扩展在保持接受长度的同时将验证开销降至接近激进剪枝的水平，有效处于 Pareto 前沿。
- 复用感知门控将专家复用率提升约 26%–33%，且对模型质量影响极小（PPL ratio 1.012–1.013，Top-1 agreement >89%）。
- 结论：S2-MoE 为边缘 MoE 推理提供了一种高效、高质量、即插即用的加速方案。
