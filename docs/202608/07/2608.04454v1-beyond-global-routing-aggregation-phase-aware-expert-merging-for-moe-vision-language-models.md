## 摘要
混合专家视觉语言模型（MoE-VLM）通过稀疏专家激活增加模型容量，但部署需要存储完整的专家池。无训练专家合并可以减少这一负担，许多基于路由的方法聚合所有令牌的路由统计以确定合并兼容性。然而，MoE-VLM推理是阶段结构的：图像上下文令牌携带视觉内容，问题令牌指定查询，答案令牌产生输出，且数量与路由分布各不相同。由于图像上下文令牌数量远多于其他令牌，全局聚合可能过度强调图像上下文处理，掩盖阶段条件下的专家角色，使服务于不同阶段的专家看似可互换，从而降低模型性能。因此，我们认为MoE-VLM专家合并应保留阶段条件下的专家角色，根据专家在不同阶段的贡献而非全局聚合的路由统计来判断兼容性。基于这一观点，我们提出RoleMerge，一种无训练方法，通过阶段归一化的路由统计构建每个专家的路由角色画像（RRP），捕捉其相对阶段偏好。在专家阶段信息损失的指导下，RoleMerge合并具有兼容画像的专家及其对应的路由器条目，同时保留答案解码专家的区分。在三个模型和多个基准上的实验表明，在相同的专家保留比例下，RoleMerge比替代专家合并方法保留了更多完整模型的性能，在六任务宏平均性能上相对提升高达9.6%。这些结果验证了阶段条件专家角色比全局路由聚合更适合作为MoE-VLM专家合并的基础。

## Abstract
Mixture-of-experts vision-language models (MoE-VLMs) increase model capacity with sparse expert activation, yet deployment requires storing the full expert pool. Training-free expert merging reduces this burden, and many routing-based methods aggregate routing statistics across all tokens to determine merge compatibility. However, MoE-VLM inference is phase-structured: image-context tokens carry visual content, question tokens specify the query, and answer tokens produce the output, with different counts and routing distributions. Because image-context tokens are far more numerous, global aggregation can overemphasize image-context processing and obscure phase-conditioned expert roles, making experts serving different phases appear interchangeable and degrading model performance. We therefore argue that MoE-VLM expert merging should preserve phase-conditioned expert roles, judging compatibility by how experts serve different phases rather than globally aggregated routing statistics. Based on this view, we propose RoleMerge, a training-free method that constructs each expert's Routing Role Profile (RRP) from phase-normalized routing statistics, capturing its relative phase preference. Guided by expert-phase information loss, RoleMerge merges experts with compatible profiles and their corresponding router entries while preserving answer-decoding expert distinctions. Experiments on three models and multiple benchmarks show that RoleMerge preserves more of the full model's performance than alternative expert-merging methods at matched expert-retention ratios, with relative improvements of up to 9.6 percent in six-task macro-average performance. These results validate phase-conditioned expert roles as a more effective basis than global routing aggregation for MoE-VLM expert merging.

### 1. 核心问题与整体含义（研究动机和背景）

- **背景**：混合专家模型（MoE）通过稀疏激活机制在增加模型容量的同时控制单 token 计算成本，已被广泛引入视觉语言模型（VLM）中，代表模型包括 DeepSeek-VL2、Qwen3-VL、InternVL3.5、Aria 等。然而，MoE 的稀疏激活只降低了计算开销，并未降低存储开销——部署时仍需保存完整的专家池，这在内存和磁盘上造成显著负担。
- **核心问题**：训练无关的专家合并（training-free expert merging）是减少专家存储的有效手段。现有基于路由的合并方法往往在全部校准 token 上聚合路由统计（全局聚合），以判断专家之间的合并兼容性。但 MoE-VLM 的推理过程具有明显的**阶段结构**：
  - 图像上下文 token（image-context）负责承载视觉内容；
  - 问题 token（question）负责描述查询；
  - 答案 token（answer）负责生成输出。
  - 这三个阶段 token 数量差异巨大（图像 token 往往远多于其他），路由分布也各不相同。
- **关键洞察**：
  - 全局聚合会因图像上下文 token 数量过多而主导统计结果，掩盖了专家在不同阶段中的真实角色；
  - 两个路由分布截然不同的专家，可能拥有完全相同的全局聚合统计，从而被误判为“可合并”，破坏推理阶段所需的路由结构，导致模型性能下降。
- **论文主张**：MoE-VLM 的专家合并应基于**阶段条件专家角色（phase-conditioned expert roles）**——即专家如何服务于不同推理阶段——而非全局聚合的路由统计。
- **整体含义**：该工作重新定义了 MoE-VLM 专家合并的兼容性判断基础，将“专家在哪些阶段被使用”纳入合并决策，为多模态 MoE 模型的高效部署提供了新视角。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 2.1 核心思想

- 将 MoE-VLM 推理拆分为三个阶段：**图像上下文处理（img）、问题处理（ques）、答案解码（ans）**。
- 为每个专家构造一个 **路由角色画像（Routing Role Profile, RRP）**，用于刻画其在三个阶段的相对使用偏好。
- 以 **专家–阶段信息损失（expert–phase information loss）** 衡量合并兼容性。
- 在合并时**保留答案解码阶段的关键专家区分**，避免因合并破坏生成质量。
- 最终将专家参数与对应路由器条目以相同组内权重一并合并，实现端到端的无训练压缩。

#### 2.2 关键技术细节

**（1）相位归一化与 RRP 构造**

- 对每个 MoE 层 ℓ，分别统计三个阶段的专家路由次数 nℓ,b(e)，b ∈ {img, ques, ans}。
- 计算阶段归一化路由分布：pℓ,b(e) = nℓ,b(e) / Σe nℓ,b(e)。
- 采用**均匀阶段先验** π(b) = 1/3，构建联合分布 Pℓ(e, b) = π(b) · pℓ,b(e)。
- 定义专家的 RRP：qℓ,e(b) = Pℓ(B=b | Sℓ=e) = Pℓ(e,b) / Pℓ(e)。
  - RRP 描述的是专家在三个推理阶段上的相对偏好，而非全局使用频率；
  - 该构造对相位长度不均等进行了归一化，使得阶段间可直接比较。

**（2）专家–阶段信息损失**

- 定义分组 cℓ 引起的专家–阶段互信息损失：
  ΔEP,ℓ(cℓ) = I_Pℓ(Sℓ; B) − I_Pℓ(Cℓ; B) = Σ_{G∈Gℓ} Σ_{e∈G} Pℓ(e) · D_KL(qℓ,e ∥ qℓ,G)
- 对于两个专家 i、j 的成对损失：
  dEP,ℓ(i, j) = Pℓ(i)·D_KL(qℓ,i ∥ mℓ,ij) + Pℓ(j)·D_KL(qℓ,j ∥ mℓ,ij)
  其中 mℓ,ij 是两个专家 RRP 的加权平均。
- dEP 越小，说明两个专家的阶段角色越互补或相似，越适合合并。

**（3）回答感知的合并得分（Answer-Aware Merge Score）**

- 由于仅靠信息损失无法避免将同一阶段（尤其是答案解码阶段）频繁使用的专家合并，论文引入**带符号碰撞调整（signed collision adjustment）**：
  - 计算每个候选组的答案解码路由质量集中度：R_ans,ℓ(G)；
  - 增量 ΔR_ans,ℓ(G,H) = R_ans,ℓ(G∪H) − R_ans,ℓ(G) − R_ans,ℓ(H)；
  - 若合并后碰撞增量上升，则提高合并得分（延迟合并）；若下降，则降低得分（提前合并）。
- 最终合并得分：
  Jℓ(G,H) = d_role,ℓ(G,H) + λℓ · ΔR_ans,ℓ(G,H) / τℓ
  - d_role 为单链式组间角色不相似度；
  - λℓ 由各层答案路由集中度 κℓ 自适应确定；
  - τℓ 为归一化尺度。
- 算法以贪心方式反复选择得分最小的组对进行合并，直到达到目标专家数 Kℓ = ρ · Nℓ。

**（4）专家与路由器参数合并**

- 组内权重：基于各专家全部阶段的原始路由计数在原组内归一化：ωℓ,e ∝ Σ_b nℓ,b(e)。
- 用相同的组内权重同时合并专家参数和路由器条目：
  - Θ̂ℓ,G = Σ_{e∈G} ωℓ,e · Θℓ,e
  - r̂ℓ,G = Σ_{e∈G} ωℓ,e · rℓ,e
- 这样一次分组同时产出压缩后的专家池和路由器，不需要重新训练任何组件。

**（5）完整算法流程（RoleMerge）**

1. 用冻结的 MoE-VLM 在校准集上运行确定性自回归推理；
2. 将路由位置划分为图像上下文 / 问题 / 答案三个阶段桶；
3. 统计各阶段专家路由次数，构建 RRP 与成对损失；
4. 计算答案路由集中度与碰撞调整，构造回答感知的合并得分；
5. 贪心合并直到达到目标专家保留数；
6. 用共享的组内权重合并专家参数与路由器条目，输出压缩模型。

- **核心结论**：阶段条件专家角色（phase-conditioned expert roles）比全局路由聚合更适合作为 MoE-VLM 专家合并的兼容性判断依据。
- **性能结果**：

- **效率结果**：

### 7. 优点

- **问题定位精准**：指出了全局路由聚合在 MoE-VLM 中的“非可辨识性”问题（两种截然不同的阶段角色可以产生完全相同的全局路由分布），并用信息论框架严格刻画。

- **实验公平性好**：所有基线在同一协议下重跑，校准与评估严格分离，并提供配对置信区间。
- **披露诚实**：作者明确不声称 TCS 校准集为最优、λ=.03 并非全局最优、ACR 非性能预测器，展现出较高的学术透明度。
- **可复现性强**：提供了详细伪代码（Algorithm 1）、精确的任务标识符、校准集构成、评估样本数和实现细节。

### 8. 不足与局限

- **模型覆盖面有限**：仅在 DeepSeek-VL2（Tiny/Small）和 Qwen3-VL 上验证，未覆盖 InternVL3.5、Aria 等更多 MoE-VLM 架构；DeepSeek-VL2-Tiny/Small 属同一家族，真正的跨架构验证仅 Qwen3-VL 一项。
- **任务类型有限**：六个基准均为单轮问答或判别式任务，未覆盖开放式生成、多轮对话、视频理解等更复杂的场景。
- **校准集敏感性**：虽然整体呈平台期，但校准源类型差异显著（混合多模态 vs 纯文本答案差 6.48 点），说明方法对校准数据构成仍较敏感；TCS 并非最优校准集，这是一个已知的未解决问题。
- **未解决参数冲突**：RoleMerge 聚焦合并兼容性，但未直接处理合并后专家内部的参数干扰问题，未来需与更高级的参数融合方法结合。
- **贪心算法非全局最优**：单链接贪心分组在理论上不保证全局最优解，搜索深度实验也显示局部搜索变体并非一致更优。
- **性能保留上限**：在 ρ=.50 时，DeepSeek-VL2-Small 仅保留完整模型 Avg 的 75.1%，压缩与性能仍存在明显权衡。
- **算力信息不完整**：未报告总计算量、合并算法运行时长、校准路由采集成本等资源指标。
- **ACR 指标解释需谨慎**：ACR 虽被明确定位为机制诊断，但在部分实验中被用来说明机制有效性，其与下游性能之间并非严格正相关。
