## 摘要
我们介绍了 Motif 3，这是一个仅解码器的混合专家语言模型，总参数为3140亿，每个词元激活132亿参数。每个稀疏MoE层包含384个路由专家，每个词元选择其中8个。这种细粒度稀疏性在限制计算的同时提供了可观的专家容量。Motif 3围绕分组差分潜在注意力（GDLA）构建，该机制将分组差分注意力与多头潜在注意力的压缩键值表示相结合。该架构进一步融入了修改后的流形约束超连接、专家特定PolyNorm激活以及多词元预测，以提升优化稳定性、专家专业化和推理效率。我们在约12.5万亿词元上预训练了Motif 3，涵盖网页文档、STEM、代码、数学、多语言内容和领域专门语料库。专家平衡和数值稳定技术支持大规模稳定训练，而选择性MXFP8计算与通信、内存高效的融合内核以及窗口感知的上下文并行性，使得最长256K词元的上下文长度训练成为可能。我们的后训练流程结合了通用监督微调、六个通过强化学习训练的专业教师、一个通过监督微调训练的软件工程教师，以及多教师在线策略蒸馏。由此产生的统一模型整合了推理、编码、工具使用、专业工作、长上下文理解、校准性弃权以及指令遵循等方面的互补能力。在广泛的评估套件中，Motif 3在与领先开源权重模型的对比中表现出具有竞争力的性能，包括在长周期智能体任务、数学推理、科学知识以及对幻觉敏感的评估中的强劲结果。

## Abstract
We introduce Motif 3, a decoder-only Mixture-of-Experts language model with 314 billion total parameters and 13.2 billion activated per token. Each sparse MoE layer contains 384 routed experts, with eight selected per token. This fine-grained sparsity provides substantial expert capacity while limiting computation. Motif 3 is built around Grouped Differential Latent Attention (GDLA), which integrates grouped differential attention with the compressed key-value representation of Multi-head Latent Attention. The architecture further incorporates modified manifold-constrained hyper-connections, Expert Specific PolyNorm activations, and multi-token prediction to improve optimization stability, expert specialization, and inference efficiency. We pretrain Motif 3 on approximately 12.5 trillion tokens spanning web documents, STEM, code, mathematics, multilingual content, and domain-specialized corpora. Expert-balancing and numerical-stabilization techniques support stable training at scale, while selective MXFP8 computation and communication, memory-efficient fused kernels, and window-aware context parallelism enable training with context lengths up to 256K tokens. Our post-training pipeline combines general supervised fine-tuning, six specialist teachers trained with reinforcement learning, a software-engineering teacher trained with supervised fine-tuning, and Multi-teacher On-Policy Distillation. The resulting unified model consolidates complementary capabilities in reasoning, coding, tool use, professional work, long-context understanding, calibrated abstention, and instruction following. Across a broad evaluation suite, Motif 3 demonstrates competitive performance against leading open weight models, including strong results on long-horizon agentic tasks, mathematical reasoning, scientific knowledge, and hallucination-sensitive evaluation.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大语言模型（LLM）能力迅速提升，在推理、编码、工具使用、长周期智能体任务上展现出巨大潜力。与此同时，开放权重模型与专有系统的差距不断缩小，MoE（混合专家）架构使得模型容量扩展不按比例增加单 token 计算成本。
- **核心挑战**：如何在超大容量模型下同时保证：
  - 专家容量充裕但单 token 计算可控；
  - 大规模训练数值稳定、路由不崩溃；
  - 后训练能统一多种互补能力（推理、编码、工具、长上下文等）。
- **研究意义**：Motif 3 验证了“细粒度稀疏架构 + 高度系统化训练优化 + 多教师蒸馏后训练”的可行路径，为下一代高效、通用、可部署的大规模 MoE 模型提供了新范式。

## 2. 提出的方法论

### 2.1 总体架构

- 仅解码器、自回归 MoE 语言模型：**总参数 314B，每个 token 激活约 13.2B 参数**。
- 53 层 Transformer：前 2 层为稠密 FFN，后 51 层为稀疏 MoE。
- 每层 384 个路由专家 + 1 个共享专家，每个 token 选择 **top-8** 个路由专家。
- 混合注意力：每 4 层中 1 层全因果注意力 + 3 层滑动窗口注意力（窗口 128 token，每 4 层全注意力）。
- 关键组件：GDLA、改进 mHC、Expert-Specific PolyNorm、MTP。

### 2.2 Grouped Differential Latent Attention（GDLA）

- **目的**：结合差分注意力（抑制噪声）与 MLA（压缩 KV 缓存）的优势，同时通过分组非对称分配提升信号建模容量。
- **核心设计**：
  - Q 通过低秩投影生成内容分量和旋转分量；KV 压缩为潜在表示，经 RMSNorm 和单次 up-projection 展开为 16 个共享 KV 头。
  - 信号头 `nS = g·nN`，噪声头 `nN = nH/(g+1)`，分组比 `g=4`（即 64 信号头 + 16 噪声头）。
  - 每个信号头配对一个重复的噪声头输出，并预测 token 级系数 `λ = σ(xWλ) ∈ (0, 1)`，做差分相减。
  - 使用 query 侧输出门控：`σ(G) ⊙ D` 后经输出投影。
- **实验结果**：约 10B 参数对照实验中，GDLA 损失低于 GDA 和 MLA，达到 3.2 损失时比 MLA 少用 9.2% 训练 token。

### 2.3 改进的流形约束超连接（mHC）

- 用可学习、token 相关的多流（n=4）混合替代残差加法，映射矩阵满足双随机约束（Birkhoff 多胞体），保持凸组合和恒等传播。
- **关键改进**：将后映射乘子从固定 2 退火到 1，避免深层堆叠导致激活离群值累积。
- Sinkhorn-Knopp 归一化和投影在 FP32 中计算。

### 2.4 Expert-Specific PolyNorm

- 每个专家独立学习多项式系数和偏置，替代固定 SiLU 门控激活：
  - `PolyNorm_i(z) = Σ_{n=1..3} a_{i,n} z^n / RMS(z^n) + b_i`
  - 多项式系数经 sigmoid 约束到 (0, 1)，偏置裁剪到 [-0.5, 0.5]。
- 实验表明该激活较 SwiGLU 保持更高的门控矩阵有效秩，促进专家分化且抑制离群值。

### 2.5 多 token 预测（MTP）

- 沿用 DeepSeek-V3 的独立 MTP 头作为辅助训练目标，支持自推测解码，不改变主解码架构。

### 2.6 训练系统优化

- **分布式**：EP=8 与 DP-shard=8，不使用流水线并行；HybridEP 做专家通信；FSDP 优化（梯度 Reduce-Scatter 重叠、跨微批次同步抑制、减少专家 All-Gather）。
- **低精度**：MXFP8 用于 MoE 专家矩阵和激活，FP32 用于主权重、梯度、路由 logits 和 Muon 状态；BF16 梯度同步。
- **长上下文**：全注意力层用 Ulysses CP，滑动窗口层用窗口感知 Ring Attention；引入跨数据并行的工作量感知重调度（LPT 贪心）。

### 2.7 MoE 训练稳定性

- FP32 sigmoid 路由 + 免辅助损失的专家偏置；
- 带衰减的 router 高斯噪声（余弦衰减）；
- 序列级负载均衡损失 + 层自适应系数；
- FFN 幅度辅助正则化（软惩罚，非硬裁切）；
- 专家健康监控（分发/输出权重/激活统计），路由崩溃时用邻近层路由参数替换。

## 7. 优点

- **架构设计新颖且高效**：GDLA 巧妙结合差分注意力与 MLA，显著降低 KV 缓存与注意力冗余；384 个专家 top-8 提供了极高容量/激活比。
- **系统优化扎实**：MXFP8 预量化、行/列转码、窗口感知 CP、工作量感知重调度等，都是大规模 MoE 训练中少见的工程细节，有助于复现。
- **稳定性方法可操作**：decaying router noise、FP32 路由、FFN 幅度正则、专家健康监控等给出具体的阈值和替代方案。
- **后训练整合独特**：六个 RL 教师 + 一个 SFT 教师 + MOPD 蒸馏，统一了多领域专家能力而不增加部署负担。
- **Tokenizer 压缩领先**：对英文、韩文、代码、数学压缩率均优于 Qwen3.5、Gemma-4、DeepSeek-V4、GPT-4o 等 tokenizer。

## 8. 不足与局限

- **评测覆盖有限**：主要集中在英文与部分多语（韩语），对中文/日文等语言评测不足；缺少视觉/多模态任务（模型本身为纯文本）。
- **对比公平性有风险**：对比模型分数取自排行榜，各自采样参数、工具版本、评测 harness 可能不一致；尤其 ITBench-AA 为公开子集结果，不宜直接与全量结果并列。
- **科学编码与前沿科学推理较弱**：SciCode 和 CritPt 明显低于领先模型，说明训练数据在后训练 RL 中未充分强化该方向。
- **资源细节缺失**：未报告 GPU 总数、训练时长、单次实验成本等，难以评估复现成本。
- **消融不完整**：对 GDLA、mHC、PolyNorm、MOPD 各自贡献缺乏端到端系统消融；长上下文阶段、FNN 正则等阈值选择也缺乏敏感性分析。
- **长上下文实际可靠性**：支持 256K 输入，但“长周期任务中的状态跟踪、规划、恢复能力”未在更长轨迹上充分验证。
- **社会影响与安全讨论缺失**：论文未涉及数据偏见、有毒内容、越狱风险等安全评价。
