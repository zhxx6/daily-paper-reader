## 摘要
大语言模型（LLMs）已取得显著进展，但其庞大的存储和内存带宽需求仍阻碍高效部署。权重二值化是一种有前景的解决方案，但现有基于二值化的训练后量化（PTQ）方法通常由于隐藏开销而远超名义上的 1 比特存储目标。为弥补这一差距，我们提出 All for 1-Bit（AF1），一个面向 LLMs 的真正 1 比特 PTQ 框架。AF1 包含两个互补组件：（1）零空间感知二值分解（NABF），通过 Hessian 感知的代理重参数化、零空间感知二值分解以及仅尺度的全局重建来改进二值重构；（2）分层 Shapley 分配（HiSA），利用分层 Shapley 敏感度分配结构容量。二者共同在 PTQ 设置下严格 1.0-BPW 预算内保持模型精度。在 LLaMA、Qwen 和 Gemma 系列上的实验表明，AF1 在困惑度和零样本准确率上持续优于现有基于二值化的 PTQ 方法。与 BF16 相比，AF1 在评估模型上平均实现 2.5 倍推理加速和超过 90% 的内存降低，为 LLMs 可部署的真正 1 比特压缩提供了实用路径。可复现代码见 https://github.com/Kishon-zzx/AF1。

## Abstract
Large language models (LLMs) have achieved remarkable progress, yet their massive storage and memory-bandwidth demands still hinder efficient deployment. Weight binarization is a promising solution, but existing binarization-based post-training quantization (PTQ) methods usually far exceed the nominal 1-bit storage target due to hidden overhead. To address this gap, we propose All for 1-Bit (AF1), a genuine 1-bit PTQ framework for LLMs. AF1 comprises two complementary components: (1) Null-space-Aware Binary Factorization (NABF) for improving binary reconstruction through Hessian-aware surrogate reparameterization, null-space-aware binary factorization, and scale-only global reconstruction; and (2) Hierarchical Shapley Allocation (HiSA) for assigning structural capacity using hierarchical Shapley sensitivity. Together, they preserve model accuracy under a strict 1.0-BPW budget in the PTQ setting. Experiments on LLaMA, Qwen, and Gemma families show that AF1 consistently outperforms existing binarization-based PTQ methods in perplexity and zero-shot accuracy. Compared with BF16, AF1 achieves an average 2.5 times inference speedup and over 90% memory reduction across evaluated models, providing a practical path toward deployable genuine 1-bit compression for LLMs. The code for reproducibility is available at https://github.com/Kishon-zzx/AF1.

## 1. 核心问题与研究动机

- **背景压力**：LLM 参数规模持续膨胀（如 LLaMA-3.1-405B、Qwen3.5-397B-A17B），BF16 精度下仅权重就需约 800 GB 显存，加上 KV cache 与激活值，部署成本极高。权重量化尤其是二值化（1-bit）因潜在的单比特存储与位级计算能力而备受关注。
- **关键矛盾**：现有基于二值化的 PTQ 方法（BiLLM、ARB-LLM、STBLLM、HBLLM）虽标称 1-bit，但因缩放因子、分组参数、显著列索引、位图等辅助元数据，**实际有效 BPW 常达 2–4 bit**，远超标称目标；而 QAT 方法（OneBit、LittleBit）虽能实现真正 1-bit，却依赖大规模训练数据、数百至上千 GPU 小时，代价过高。
- **两个根本障碍**：
  - 单矩阵二值化（W ≈ αB）表示能力有限，难以刻画 LLM 权重的复杂幅度分布与结构相关性，且 PTQ 只有少量校准数据与优化步数，误差控制要求更严。
  - LLM 各层与子模块对二值化误差的敏感度高度异质，统一配置或固定结构预算会导致次优容量分配与全模型性能退化。
- **研究含义**：如何在严格 1.0 有效 BPW 预算下、以 PTQ 级成本实现真正 1 比特压缩，是端到端高效 LLM 推理的关键挑战。

## 2. 方法论：AF1 框架

### 2.1 整体思想
AF1 = **NABF**（零空间感知二值分解，提升二值重建精度）+ **HiSA**（分层 Shapley 分配，优化结构预算），二者协同在严格 1.0 有效 BPW 下保持精度。

### 2.2 NABF（Null-space-Aware Binary Factorization）
- **Hessian 感知代理重参数化**：借鉴 K-FAC 对角近似，定义输入重要度向量 $i_j=\sqrt{E[x_j^2]}$、输出重要度向量 $o_u=\sqrt{E[g_u^2]}$，将权重重参数化为 $W' = o \odot W \odot i^\top$，把 Hessian 加权重建转化为代理空间中的 Frobenius 目标，使后续二值分解聚焦任务敏感通道。
- **双因子二值分解**：将 $W'$ 分解为两个二值符号矩阵与连续缩放向量的乘积（式 4），相比单矩阵二值化具有严格更强的幅度表达能力（附录证明其幅度矩阵可非秩一，突破单因子的乘法一致性约束）。
- **零空间感知补偿（核心创新）**：ADMM 求解连续代理后经 SVID 投影回二值域，产生投影残差 $E_A=\hat{A}-A_q$。利用固定因子 $B$ 的未中心化协方差 $C_B=BB^\top$ 的零特征空间等价于 $B$ 的左零空间这一性质，构造近似零空间投影算子 $P_B=\hat{U}\hat{U}^\top$（阈值 $\eta=0.01$ 的自适应残差能量截断），将残差引导至对前向映射影响可忽略的方向：$A_{target}=\hat{A}-E_AP_B$。再通过闭式最小二乘解 $\gamma^* = \mathrm{diag}(A_q^\top A_{target})/\mathrm{diag}(A_q^\top A_q)$ 将补偿折叠进中间缩放向量 $m_1$，**不改变二值符号矩阵与推理计算图**。
- **仅尺度全局重建**：冻结所有二值符号矩阵，仅以全精度模型为教师，用 KL 散度目标优化缩放参数 $\{a,m,b\}$，可训练参数量从 $O(d_{out}r + rd_{in})$ 降至 $O(d_{out}+r+d_{in})$。

### 2.3 HiSA（Hierarchical Shapley Allocation）
- **层间粗粒度分配（渐进 Shapley）**：以端到端 token 级 NLL 为价值函数，沿 Monte Carlo 采样排列逐层将中间维度从 $r_{orig}$ 降至 $r_{proxy}$，计算边际 NLL 增量并平均得 Shapley 分数 $\Phi_l$；经温度控制 softmax 转化为层预算 $B_l$。该估计天然建模跨层误差传播与交互。
- **模块级细粒度分配（双敏感度 Shapley）**：在层内对子模块（Q/K/V/O/Up/Gate/Down）构建合作博弈，分别以**方向失真** $r_{dir}$（角度漂移，影响注意力匹配）与**幅度失真** $r_{mag}$（相对激活能量偏移，影响残差流）为度量，采用单调累积误差避免负边际；经 MAD 稳健 Z-score 归一化、Sigmoid 映射后以 Soft-OR 融合 $v_{base}=1-(1-P_{dir})(1-P_{mag})$，防止任一失效模式被平均掩盖。
- **尺寸感知敏感度密度**：以 $b_i \propto |W_i|(v_{base}/|W_i|+\epsilon)^\alpha$ 分配，平滑指数 $\alpha$ 在"按尺寸分配"与"按脆弱度分配"间插值，避免大模块主导预算、小模块估计噪声被放大。
- **预算到秩的转换**：$r_i = \mathrm{Round}(b_i d_{out}d_{in}/(d_{out}+d_{in}))$。

- AF1 在 2.50-bit 下于所有模型上取得最优；相比最强基线 HBLLM，平均零样本准确率提升超 20%，WikiText2 PPL 降低超 90%。

## 7. 优点

- **真正 1.0 BPW 的严格定义**：附录系统推导各基线的有效 BPW，指出其隐藏元数据开销，并在自身方法中只保留二值因子与轻量缩放向量，存储预算可控、部署时无需显著掩码/位图/残差张量。
- **零空间补偿的数学优雅性**：将离散投影残差引导至固定因子的近似零空间，并以闭式最小二乘折叠进已有缩放向量，不增加推理图复杂度，实现"零推理开销"的误差吸收。
- **交互感知的容量分配**：用 Shapley 值而非孤立局部敏感度来建模跨层误差传播，并以方向/幅度双失真刻画不同子模块的失效模式，Soft-OR 融合与尺寸感知密度设计具有理论动机（含秩一约束反例、MSE 分解证明等）。
- **实验规模与工程落地性**：跨 3 家族多规模模型、覆盖 PPL/零样本/推理/代码/数学、附带真实 GPU 吞吐与内存基准、开源代码，且校准数据敏感性低，实用性强。
- **写作与附录完备**：32 页含详细算法伪代码、多组证明、BPW 推导、定性生成示例与 LLM 使用声明，可复现性较好。

## 8. 不足与局限

- **仅权重二值化**：不压缩激活与 KV cache，在长上下文或大 batch 服务场景中，KV cache 可能成为新瓶颈，端到端收益受限。
- **效率评估范围有限**：基于特定 GPU 与 GemLite 的优化实现，未集成到更广泛推理栈（如 vLLM/TensorRT-LLM），实际部署收益需进一步验证。
- **模型与任务覆盖**：仅覆盖 LLaMA、Qwen、Gemma 及标准语言基准，未验证更多架构、更广指令微调变体与真实业务负载。
- **硬件信息不完整**：未说明 GPU 数量与集群规模，量化总成本（尤其 HiSA 的多轮 NLL 前向评估）的可扩展性缺乏细节。
- **分配开销**：HiSA 需要多次完整模型 NLL 评估（$M_{layer}=60$、$M_{block}=40$ 次采样），虽比 QAT 便宜，但对超大模型（400B 级）的实际可行性未做验证。
- **定性示例依赖外部 LLM 评审**（GPT-5.5），评审主观性可能引入偏差；且示例仅限客观短问答，未覆盖长文本生成等更易暴露退化的场景。
- **伦理风险**：高效压缩可能降低模型滥用门槛，作者建议沿用全精度

模型的安全对齐、许可与滥用监测机制；但论文未给出具体可操作的缓解措施或风险量化实验，因此该讨论更多是原则性声明。

## 9. 总体评价与启示

- **方法定位**：AF1 的核心贡献不是单纯追求“更低比特”，而是在严格 **1.0 有效 BPW** 约束下重新界定二值 PTQ 的精度边界。它同时回应了两个常被混为一谈的问题：二值表示能力不足，以及压缩预算在层/模块间分配不当。
- **核心洞见**：
  - 二值化产生的投影残差不必被完全消除，而可被引导至对前向映射影响较小的近似零空间，再以闭式最小二乘折叠进已有缩放参数，从而做到“吸收误差但不增加推理图复杂度”。
  - 容量分配应显式建模跨层误差传播与模块间交互，而非依赖均匀预算或孤立局部敏感度；Shapley 值、方向/幅度双失真与尺寸感知密度共同构成了一个可解释的分配框架。
- **对领域的意义**：
  - 论文对基线“有效 BPW”的系统推导提醒社区：标称 1-bit 与真实存储/计算开销之间存在显著差距，未来二值化或极低比特工作宜将元数据、缩放因子、索引与位图开销纳入统一报告。
  - 零空间感知补偿与分层 Shapley 分配具有一定通用性，可迁移到稀疏化、混合精度、结构化剪枝或其他离散优化型压缩任务。
  - AF1 表明，在 PTQ 级成本下，真正 1-bit 权重压缩与接近 QAT 的精度并非不可兼得，但前提是表示增强与预算分配必须协同设计。
- **适用边界**：AF1 更适合权重存储受限、解码阶段内存瓶颈明显、且可接受少量校准与分配开销的部署场景；若服务瓶颈主要来自 KV cache、长上下文激活或超大 batch，则仅权重二值化的端到端收益会被削弱。
- **未来方向**：
  - 将 NABF/HiSA 扩展至激活、KV cache 或联合权重-激活量化；
  - 与 vLLM、TensorRT-LLM 等主流推理栈深度集成，验证真实服务吞吐与尾延迟；
  - 在 100B+ 参数、长上下文、多模态及更广指令微调变体上验证可扩展性；
  - 降低 HiSA 多次完整 NLL 前向评估的成本，或设计更廉价且方差更低的交互敏感度估计；
  - 引入输入自适应或动态缩放机制，并加强压缩模型的安全、偏差与鲁棒性评估。
