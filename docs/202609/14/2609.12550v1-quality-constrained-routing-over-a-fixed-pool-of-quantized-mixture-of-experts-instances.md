## 摘要
量化混合专家（MoE）服务可以保存同一基础模型的多个预物化实例，但量化损伤会因请求和位宽的不同而剧烈变化。由于实例物化和副本数量会消耗内存并需要缓慢的重配置，我们将其视为上游供给决策，并研究固定常驻池内的路由。在这一固定池边界内，我们为每个请求进行路由，以在类别级期望质量退化预算和实测实例容量下最大化建模吞吐量。为了预测这种请求特定的风险，我们引入 FWP（脆弱性加权困惑度），它根据参考实例预填充上的提示 token 计算，并针对候选实例退化进行校准。FWP 的基础是一个精确的双专家亲和性—脆弱性分解，以及一个条件式多层 top-k 展开，其偏置、交互、路由变化、可分离性和高阶项均保持显式。利用这些校准后的风险，窗口级线性规划产生一个带符号的缩减奖励得分，该得分在最优价格和原始可行平局分配下与 LP 最优解 KKT 一致。在 88 个扩展 Qwen 提示上，量化全部 6,144 个专家块的完整 W2、W3 和 W4 实例分别带来 0.9437、0.1832 和 0.0513 的平均 ΔNLL。在相同总体和 τ=0.1513 下，FWP 分配达到 1.284 倍的离线基于模型乘数，而请求无关混合为 1.253 倍，静态 W4 为 1.000 倍，带来了 2.5% 的相对 FWP 增量增益。

## Abstract
Quantized Mixture-of-Experts (MoE) services can hold several pre-materialized instances of one base model, but quantization damage varies sharply across requests and bitwidths. Because instance materialization and replica counts consume memory and require slow reconfiguration, we treat them as upstream provisioning decisions and study routing within a fixed resident pool. Within this fixed-pool boundary, we route each request to maximize modeled throughput under a class-level expected quality-degradation budget and measured instance capacities. To predict this request-specific risk, we introduce FWP (Fragility-Weighted Perplexity), computed from prompt tokens on a reference-instance prefill and calibrated to candidate-instance degradation. Underlying FWP is an exact two-expert affinity--fragility decomposition and a conditional multi-layer top-$k$ expansion whose bias, interaction, route-change, separability, and higher-order terms remain explicit. Using these calibrated risks, a window-level linear program yields a signed reduced-reward score that is KKT-consistent with the LP optimum under optimal prices and primal-feasible tie allocation. On 88 extended Qwen prompts, complete W2, W3, and W4 instances quantizing all 6,144 expert blocks incur mean $Δ$NLL of $0.9437$, $0.1832$, and $0.0513$. Under the same population and $τ=0.1513$, FWP allocation reaches a $1.284\times$ offline model-based multiplier versus $1.253\times$ for request-agnostic mixing and $1.000\times$ for static W4, an incremental $2.5\%$ relative FWP gain.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：稀疏 MoE 模型参数容量大但每 token 仅激活少量专家，后训练专家量化是重要的内存与吞吐手段。然而量化损伤具有高度异质性：同一批请求上，不同位宽的实例质量损失差异巨大。
- **关键观察**：在 88 条 Qwen 请求上，完整实例 W2/W3/W4 的平均 ΔNLL 分别为 0.9437 / 0.1832 / 0.0513，而 W3 的中位数仅 0.1387——总体均值与请求级结果之间的落差构成了分配机会。
- **两时间尺度边界**：实例物化与副本数决定参数常驻、消耗内存、需要缓慢重配置，属于**上游供给决策（外问题）**；论文聚焦于在该向量固定后、在不可变常驻池内的**请求级质量约束路由（内问题）**。作者明确不声称所评估的 W2/W3/W4 池是全局最优的机队预算使用方式。
- **核心问题**：服务系统应如何在每个请求上，按池内实例进行路由，以在**类别级期望质量退化预算**与**实测实例容量**下最大化建模吞吐量？
- **实践依据**：DeepSeek-V3 每约十分钟调整一次冗余高负载专家，而请求派发在更快的时间尺度上发生，支持这一两时间尺度抽象。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 风险信号 FWP（脆弱性加权困惑度）

- **设计动机**：结合专家脆弱性（量化敏感度）与专家亲和性（请求对该专家的激活强度）。
- **构造**：对非填充 prompt token，取被激活专家的平均 router norm $\bar\Lambda_i$，构造请求内归一化权重 $w_i \propto (\bar\Lambda_i+\epsilon_w)^{-1}$，再对 token 级 NLL 加权平均得到 $\ell_{FWP}$。
- **请求局部性**：仅使用本请求 token，不引入其他请求或 padding 位置。
- **在线使用**：在参考实例上做一次 prefill 得到原始 FWP 值，离线校准映射结合 prompt 长度与声明的类别特征，预测候选实例退化；不使用不可得的全精度分数。

### 2.2 理论基础（分层声明）

- **精确双专家亲和—脆弱分解**：$\Delta Q(b)=\alpha\Delta_r(b_r)+(1-\alpha)\Delta_c(b_c)$，将损失精确分解为亲和权重（使用频率）与内在脆弱函数（量化损伤）。
- **中心噪声约化形式（Theorem 3.1）**：在零均值扰动下，一阶项消失，主导项为 $2^{-2b}$，系数 $c_j=\tfrac12\ell''(m_j)v_j>0$；偏置噪声则对应独立的 $2^{-b}$ 有符号分支（Lemma B.2），二者不可混用。
- **条件式多层 top-k 扩展（Theorem B.2）**：显式保留偏置、交互、可分离性、路由变化（$E_{flip}$）与泰勒余项，明确指出 affine transfer 只是对固定评估实例的经验校准，而非普适定理。
- **FWP 放大恒等式（Proposition 3.1）**：$\Delta\ell^{audit}_{FWP}-\Delta\ell=\mathrm{Cov}_i(w_i,d_i)$，即 FWP 放大平均退化当且仅当逆 router norm 权重与 token 退化在请求内具有正协方差；双专家 top-1 模型中该协方差恒为零，故该模型只能启发机制、不能证明放大性质。

### 2.3 LP 路由与 KKT 一致分数

- **窗口级 LP**：以类别-实例流量 $x_{ga}\ge 0$ 最大化服务 token 数 $\sum L_g x_{ga}$，约束为需求、实例容量、以及**带符号**的类别平均质量约束 $\sum_a(\hat\ell_{ga}-\tau_g)x_{ga}\le 0$（允许低于预算的分配抵消高于预算的分配；改用单侧 hinge 会定义不同问题，KKT 声明不适用）。
- **对偶与分数**：容量价格 $\pi_a$、类别质量价格 $\nu_g$，得到一步缩减奖励 $R_{ga}=L_g-\pi_a s_{ga}-\nu_g q_{ga}$（$q_{ga}=\hat\ell_{ga}-\tau_g$）；加入配额赤字项 $d_{ga}$ 得实现分数 $S_{ga}=\beta d_{ga}+L_g-\pi_a s_{ga}-\nu_g q_{ga}$，其中 $\beta=0$ 才是精确拉格朗日缩减奖励。
- **KKT 一致性（Theorem 3.2 / C.2）**：在最优价格下，所有正流量路径最大化缩减奖励；按原始最优比例分配平局则与 LP 最优解 KKT 一致；**任意贪心平局规则仅满足稳定性**，不保证需求、容量或质量可行性。
- **在线决策**：$a^*_t(g)=\arg\max_{a\in A}S_{ga}(t)$，每请求 $O(|A|)$ 次打分；价格每控制窗口更新一次（投影次梯度，Theorem C.1 给出 $O(1/\sqrt T)$ 级收敛率）。
- **参考流程（Algorithm 1）**：若前缀长度低于验证阈值或超出校准支撑则回退保守高比特实例；否则在参考实例 prefill、计算分数、选择目标；若目标非参考实例，则因 KV 不可跨量化实例迁移而需丢弃并**计费第二次 prefill**。

## 6. 主要结论与发现

- **完整实例质量**：W2/W3/W4 平均 ΔNLL 为 0.9437 / 0.1832 / 0.0513，中位数 0.8514 / 0.1387 / 0.0241，90 分位 1.4517 / 0.4081 / 0.1800；W3 均值超出头条预算但中位数低于预算，确立请求异质性。
- **分配增益**：在 τ=0.1513 下，静态 W4 为 1.000×，请求无关混合 1.253×，**FWP 1.284×**，受限真实损失排序 1.303×。即 0.284 的倍数提升中 0.253 来自异质预算分配，FWP 仅贡献 0.031 个倍数点，即相对请求无关混合 **2.5% 的相对增益**，并弥补了到真实损失排序约 62% 的剩余差距。
- **重要澄清**：1.284× **不应**解读为 28.4% 的 FWP 吞吐增益，且该数字是离线基于模型的总体分配量，非实测路由吞吐。
- **信号有效性**：同实例 FWP 相关性 0.999/0.998 只是测量合理性检查；可部署场景下 W2 分数预测 W3 风险的 Spearman 为 0.586、AUROC 为 0.747；前缀相关性从 64 token 的 0.238 升至 1024 token 的 0.999，支持**长度感知的弃权（abstention）**而非普适保证。
- **内存与容量**：固定异质池比单个 W4 实例多 25.99 GiB 参数内存，但少于三个 W4 副本或一个 BF16 实例；这**不**意味着它是最优机队，KV 容量、批处理、张量并行与端点内核可能逆转仅参数层面的比较。
- **最终结论**：在固定常驻池条件下，请求特定风险可以改善相对于请求无关混合的分配；但证据支持的是固定池分配研究，尚不支持端到端部署保证。

## 7. 优点

- **问题刻画清晰**：将供给（副本选择、内存、重配置）与路由（请求分配）显式分离为两个时间尺度，边界明确，避免了对全局机队最优性的过度声称。
- **理论声明克制且分层**：精确分解、二阶约化、条件式 top-k 桥接、请求内协方差恒等式、LP KKT 一致性各自限定成立条件，并明确指出双专家模型无法证明部署 FWP 的放大性质。
- **方法论有据可依**：从 LP 对偶严格导出带符号缩减奖励，说明单侧 hinge 会定义不同问题，并明确平局分配与价格收敛是独立的可行性条件。
- **实验归因诚实**：把增益拆解为分配与 FWP 两部分，避免把总体提升归功于风险信号；明确区分六类证据，禁止跨协议融合。
- **局限披露充分**：主动列出 prompt-only 预测偏弱、短前缀失效、held-out 合规率不足、二次 prefill 成本、缺少等资源副本实验、LP 控制器未部署等限制。
- **轻量开销数据**：报告 FWP 插桩仅增加 3.1%/4.9% 参考 prefill、CPU LP 约 1.47–1.57 ms/窗口、三实例打分 1.63 μs/请求，为工程可行性提供参考。
