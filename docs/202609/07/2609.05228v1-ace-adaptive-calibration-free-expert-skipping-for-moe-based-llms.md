## 摘要
混合专家（MoE）架构为扩展大型语言模型（LLM）提供了一种高效范式，但固定的top-k路由会为每个token激活相同数量的专家槽位，导致大量冗余计算。现有的专家跳过方法通常依赖路由置信度、校准数据或额外训练，因此无法可靠估计被路由专家的实际贡献。为此，我们提出ACE，一种无需训练、无需校准且保留检查点的框架，用于基于MoE的LLM中的token自适应专家跳过。ACE包含两个互补组件：1）全局频谱代理（GSP），从耦合的gate、up和down投影以及RMSNorm缩放中估计全局变换能力；2）路由条件细化（RCR），从中心化的路由权重构建专家特定方向原型，并沿路由偏好方向评估专家响应。在推理期间，ACE将这两种估计与运行时路由门控相结合，仅当两个视图均将某个专家槽位识别为低贡献时才跳过它，同时始终保留top-1专家。所有专家统计量均离线计算，在线仅保留查表操作和轻量级标量运算。在三个基于MoE的LLM和八个基准上的大量实验表明，ACE持续优于现有的静态和动态基线，在激进的专家跳过下优势愈发明显。例如，在Qwen3.6-35B-A3B上以50%的跳过比例，ACE将WikiText-2困惑度降低了7.96%，并将平均下游准确率比最强竞争方法提高了4.15个百分点。

## Abstract
Mixture-of-Experts (MoE) architectures provide an efficient paradigm for scaling large language models (LLMs), yet fixed top-k routing activates the same number of expert slots for every token, causing substantial redundant computation. Existing expert-skipping methods often rely on router confidence, calibration data, or additional training, and therefore cannot reliably estimate the actual contribution of routed experts. To this end, we propose ACE, a training-free, calibration-free, and checkpoint-preserving framework for token-adaptive expert skipping in MoE-based LLMs. ACE contains two complementary components: 1) Global Spectral Proxy (GSP), which estimates global transformation capacity from the coupled gate, up, and down projections together with RMSNorm scaling; and 2) Router-Conditioned Refinement (RCR), which constructs expert-specific direction prototypes from centered router weights and evaluates expert responses along routing-preferred directions. During inference, ACE combines both estimates with runtime router gates and skips an expert slot only when both views identify it as low-contribution, while always retaining the top-1 expert. All expert statistics are computed offline, leaving only table lookups and lightweight scalar operations online. Extensive experiments across three MoE-based LLMs and eight benchmarks demonstrate that ACE consistently outperforms existing static and dynamic baselines, with increasingly pronounced advantages under aggressive expert skipping. For instance, at a 50% skipping ratio on Qwen3.6-35B-A3B, ACE reduces WikiText-2 perplexity by 7.96% and improves average downstream accuracy by 4.15 percentage points over the strongest competing method.

## 一、核心问题与研究动机

- **背景**：Mixture-of-Experts（MoE）架构通过稀疏激活（如固定 top-k 路由）在扩大模型容量的同时控制单 token 计算量，是当前大语言模型扩展的主流方式（如 Qwen3.6-35B-A3B、DeepSeek-V4 系列）。然而，固定 top-k 路由为每个 token 激活相同数量的专家槽位，不区分实际贡献度，存在大量冗余计算。
- **问题**：
  1. 路由器门控值只反映专家间相对“路由偏好”，并不等于该专家真实产生的 MoE 输出贡献；
  2. 现有专家跳过方法（基于 router confidence、校准数据、额外训练或敏感度 profiling）无法在无校准数据的条件下可靠估计被路由专家的实际贡献；
  3. 专家贡献具有方向性：与路由偏好方向相关的局部响应可能强于全局平均表现，仅靠静态全局评分会误删“方向特化”专家。
- **核心目标**：提出一种无需训练、无需校准数据、保留原始 checkpoint 的 token 级自适应专家跳过方法，在高跳过率（如 40%–60%）下仍保持较高模型质量与推理加速比。

## 二、方法论：ACE 框架

ACE 分为两个互补的离线参数统计模块和一个在线跳过决策机制，核心设计为“双视图（全局结构视图 + 路由条件方向视图）都判定低贡献才跳过”，并始终保留 router top-1 专家。

### 1. 全局频谱代理（Global Spectral Proxy, GSP）

- **思想**：直接由 SwiGLU 专家自身的参数评估其“全局变换容量”，不依赖任何真实输入或校准集。
- **数学基础**：对输入做 RMSNorm 尺度分解后，可推导 SwiGLU 专家输出范数的上界：
  ∥ f(x) ∥₂ ≤ ∥x̄∥² · ∥ΓW_gate∥₂ · ∥ΓW_up∥₂ · ∥W_down∥₂，表明输出响应由 gate、up、down 三个投影矩阵的谱范数以**乘法耦合**方式共同决定。
- **构造方式**：GSP 设计了两个分支对称的 Frobenius 范数代理：

  路径1：a_up = ∥ΓW_up∥_F · ∥ΓW_gate · W_down∥_F  
  路径2：a_gate = ∥ΓW_gate∥_F · ∥ΓW_up · W_down∥_F  
  然后用几何平均聚合：â_GSP = sqrt(a_up · a_gate)，并在层内做均值归一化得到 A_GSP(e)。
- **作用**：A_GSP > 1 表示该专家结构上具有高于本层平均的全局放大能力；在线时将其与当前 token 的 router gate 相乘并做 top-k 内归一化，得到相对 GSP 贡献分布。

### 2. 路由条件细化（Router-Conditioned Refinement, RCR）

- **动机**：GSP 是“无条件”的，无法刻画专家在具体输入方向上的响应差异。论文利用 router 权重本身构造专家特定的输入方向原型，实现无校准的方向性估计。
- **方法**：
  - 将层内所有专家 router 权重减去均值实现中心化（可证明 softmax 路由对共享平移不变，故中心化保留判别方向）；
  - 在高斯输入近似 + 指数倾斜分布假设下，专家条件均值偏移近似正比于 Σ·w̄；在各向同性协方差假设下，方向与中心化路由权重对齐；
  - 对中心化向量做 RMS 归一化得到方向原型 q_l,e（尺度置为 1），并在离线阶段将 q 分别送入对应 SwiGLU 专家做一次完整前向；
  - 原始 RCR 放大值 = ∥f(q)∥₂/∥q∥₂，再做层内均值归一化得到 A_RCR(e)。
- **作用**：衡量专家沿其“路由偏好方向”的条件响应强度，弥补 GSP 忽略方向特化的不足。

### 3. 在线自适应跳过决策

- 对每个 top-k 路由槽位分别计算 s_GSP = gate × A_GSP(e)、s_RCR = gate × A_RCR(e)，各自在 top-k 内归一化得到 p_GSP、p_RCR；
- 最终贡献分数取两个归一化分数的最大值：c_ACE = max(p_GSP, p_RCR)；
- 等价于“候选跳过集合 = GSP 低贡献集 ∩ RCR 低贡献集”的交集规则；仅当两视图同时判定其为低贡献时才跳过；
- 始终保留原始 router 中 gate 最大的 top-1 专家，并可设置单 token 最少活跃专家数；
- 对保留专家 gate 做重归一化后聚合输出；
- 论文从理论上证明该交集规则在跳过 router 概率质量、worst-case 输出扰动上界方面均不差于任一单视图规则。

## 六、主要结论与发现

- ACE 在低

跳过率（10%–20%）下几乎无损（PPL 与下游精度接近全模型）；在 40%–60% 的高跳过区间，ACE 始终好于所有对比方法，且与最强竞争方法（动态方法如 MoDES、SERE）的差距随跳过率上升而扩大。以 60% 跳过率为例，ACE 在 Qwen3-30B-A3B-Instruct-2507 上仍能保留大部分任务精度，而多数基线在该区间出现显著退化甚至崩溃。

- **性能表现**：ACE 在保留大多数下游任务精度的同时，实现了端到端推理加速（A100 上 TTFT 1.72–2.25×，TPOT 1.31–1.41×）；该加速收益在长序列、小 batch 下尤为明显，说明专家跳过直接减少了 MoE 前向计算中的大矩阵乘和内存搬运开销。
- **设计优势**：双视图“交集式”跳过规则的鲁棒性在消融中得到验证——GSP 单独工作时有较好的全局一致性，但在方向特化专家上会误删；RCR 单独工作在低跳过率时表现不错，但在高跳过率时由于只覆盖单一方向原型而快速退化；ACE 通过取两者归一化分数的最大值形成交集规则，有效规避了各自的盲区。
- **阈值可迁移性**：一次性获得的阈值可在不同任务、不同 workload 间直接复用而无需重新校准；相比之下，需要逐任务搜索阈值的 MoDES 或基于敏感度排序的静态方法在实际部署中的适配成本更高。
- **理论保证**：从路由概率质量和最坏情况输出扰动上界两个角度，证明“双视图低贡献才跳过”是保守且安全的，为实际效果提供了理论解释。

## 七、总体评价与启示

ACE 的贡献在于将“无校准、无训练、原始权重不变”的约束与 token 级自适性结合起来，用两类互补的离线统计量（结构谱代理与路由方向响应）替代了对真实输入分布的依赖，从而在不改动模型参数的前提下实现可插拔的推理加速。相比此前依赖校准数据或敏感度 profiling 的方法，ACE 在部署友好性上具有明显优势，尤其适合 checkpoint 只读、无验证集或隐私受限的场景。同时，其“最大归一化分数 + 交集跳过”的决策逻辑也启发了一种通用的低贡献专家判别框架，可推广到其他稀疏激活结构。不过，论文在实验严谨性上仍留有提升空间：缺少多轮置信区间、任务覆盖面偏代码与推理、阈值生成仍需少量同分布 pass 等，后续工作可在此基础上引入动态 batch 感知策略或兼容量化/剪枝管线，以进一步提升实际应用的覆盖面。
