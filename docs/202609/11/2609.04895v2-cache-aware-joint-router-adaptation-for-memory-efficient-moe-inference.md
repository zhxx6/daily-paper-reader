## 摘要
混合专家（MoE）模型每个 token 仅激活少量专家，但其完整专家集合可能超出 GPU 内存，并在解码过程中需要反复传输权重。我们将专家缓存管理形式化为模型侧算法问题，并提出缓存感知的后训练方法，在保留原生推理时 Top-K 规则的同时，联合适配 MoE 主干与轻量级辅助路由器。仅更新的时序路由器（Temporal Router）学习跨 token 的同层保留，而无需主动加载。完整的时空路由器（Spatio-Temporal Router）增加了一个空间路由器（Spatio Router），其利用因果前驱的隐藏状态在访问目标层之前细化时序缓存。我们在 Qwen3 和 GPT-OSS 上，于 GSM8K、MATH 和 CommonsenseQA 上评估了两种模式。与匹配的仅语言模型（LM-only）基线相比，时序路由器持续提升命中率并减少专家权重传输流量。在 Qwen3 上，相对于评估中最强的预取基线，完整模式将调整后命中率提升 1.15--18.03 个百分点，并将流量降低 4.6--53.3%；GPT-OSS 的结果具有竞争力，但依赖于任务。仅训练辅助路由器可保持基线准确率，但带来的覆盖率提升有限；联合后训练则实现显著更高的覆盖率。敏感性分析区分了缓存容量、细化预算和缓存损失权重对覆盖率、流量和质量的影响。

## Abstract
Mixture-of-Experts (MoE) models activate few experts per token, yet their full expert sets can exceed GPU memory and require repeated weight transfers during decoding. We formulate expert-cache management as a model-side algorithmic problem and propose cache-aware post-training that jointly adapts the MoE backbone and lightweight auxiliary routers while preserving the native inference-time Top-K rule. The update-only Temporal Router learns same-layer retention across tokens without proactive loading. The full Spatio-Temporal Router adds a Spatio Router that uses the causal predecessor's hidden state to refine the temporal cache before target-layer access. We evaluate both modes on Qwen3 and GPT-OSS across GSM8K, MATH, and CommonsenseQA. Temporal Router consistently improves hit rate and reduces expert-weight traffic over matched LM-only baselines. On Qwen3, the full mode improves adjusted hit rate by 1.15--18.03 points and reduces traffic by 4.6--53.3\% relative to the strongest evaluated prefetching baseline; GPT-OSS results are competitive but task-dependent. Auxiliary-only training preserves baseline accuracy but yields modest coverage gains; joint post-training achieves substantially higher coverage. Sensitivity analyses distinguish the effects of cache capacity, refinement budget, and cache-loss weight on coverage, traffic, and quality.

## 2. 论文提出的方法论

### 2.1 核心思想

- 原生 MoE 路由器仍负责选择当前 token 实际执行的 Top-K 专家，辅助路由器**不覆盖**该选择。
- 辅助路由器只控制**专家缓存驻留与预取优先级**，通过缓存感知损失与语言建模损失联合训练。
- 两种模式：
  - **Temporal Router**：仅更新式，访问后学习同层跨 token 保留，不主动加载。
  - **Spatio-Temporal Router**：在 Temporal 基础上增加因果前驱预测，在目标层访问前精炼缓存，允许有界主动加载。

### 2.2 统一缓存路由框架

- 每层维护容量为 \(B\) 的专家缓存 \(C_{t,l}\)，\(B \ge K\)。
- 原生路由器输出 \(p^R_{t,l}=\mathrm{softmax}(W^R_l h_{t,l})\)，并执行 \(S_{t,l}=\mathrm{TopK}(p^R_{t,l})\)。
- 缓存决策分两类：
  - **Post-access retention**：访问后保留，无法阻止已完成访问的 miss。
  - **Pre-access refinement**：访问前利用因果信息改善驻留，可能产生主动加载。
- 使用软 Top-B 成员代理：
  - \(m_e(s)=\sigma((s_e-\theta_B(s))/\tau)\)，其中 \(\theta_B(s)\) 是优先级 \(s\) 的第 \(B\) 大值。
  - 覆盖损失：\(\ell_{\text{cache}}(s,q)=\sum_{e=1}^N q_e(1-m_e(s))\)。
  - 使用完整原生路由器分布 \(q\) 作为软目标，而非硬 Top-K 标签，以保留边界不确定性。

### 2.3 Temporal Router：访问后保留

- 计算时序路由分布：\(p^T_{t,l}=\mathrm{softmax}(W^T_l h_{t,l})\)。
- 组合优先级：\(s^T_{t,l}=p^R_{t,l}+p^T_{t,l}\)。
- 训练目标用下一 token 同层原生分布监督：
  - \(\ell^T_{t,l}=\sum_e p^R_{t+1,l,e}(1-m_e(s^T_{t,l}))\)。
  - 总损失：\(L=L_{\text{LM}}+\lambda_T L_T\)。
- 推理时：
  - 原生路由器访问 \(C^T_{t,l}\)，对缺失的已选专家执行 demand-load，并执行该层。
  - 访问后更新：\(C^T_{t+1,l}=U_B(C^T_{t,l},S_{t,l},s^T_{t,l})\)。
  - 更新规则：插入当前已 demand-load 的选中专家，保护所有 \(S_{t,l}\) 中专家，必要时按最低优先级驱逐非选中驻留者。
  - **不引入主动传输**，所有插入都来自已完成的访问。

### 2.4 Spatio-Temporal Router：访问前精炼

- 增加 Spatio Router：\(p^S_{t,l}=\mathrm{softmax}(W^S_l h_{t,l})\)，用于预测因果执行顺序中的下一个 MoE 位置。
- 目标 \((t,l)\) 的因果前驱：
  - \(l=1\) 时，\(\rho(t,l)=(t-1,L)\)；
  - \(l>1\) 时，\(\rho(t,l)=(t,l-1)\)。
- 预访问优先级：
  - \(a^T_{t,l}=p^R_{t-1,l}+p^T_{t-1,l}\)；
  - \(s^{ST}_{t,l}=a^T_{t,l}+p^S_{\rho(t,l)}\)。
- 训练目标用当前原生分布监督：
  - \(\ell^{ST}_{t,l}=\sum_e p^R_{t,l,e}(1-m_e(s^{ST}_{t,l}))\)；
  - \(L=L_{\text{LM}}+\lambda_{ST}L_{ST}\)。
- 推理时：
  - 在 \(s^{ST}_{t,l}\) 下取 Top-R 候选，按优先级降序检查。
  - 非驻留候选只有在分数高于最低优先级驻留者时才替换，每次插入是主动加载。
  - 之后原生路由器选择 \(S_{t,l}\)，demand-load 剩余 miss，执行层。
  - 最后执行与 Temporal 相同的访问后更新。

### 2.5 训练与部署模式

- **主运行**：联合训练完整主干与辅助路由器，原生分布可微，缓存损失可反过来适配专家需求。
- **LM-only 参考**：无辅助路由器，只优化 \(L_{\text{LM}}\)，即 \(s_w=0\)。
- **Auxiliary-only 控制**：冻结 LM-only 主干，只训练辅助路由器，用于区分“固定表示上的预测”与“联合适配”。
- **路由器初始化**：复制原生路由器权重，而非随机初始化：
  - \(W^T_l \leftarrow W^R_l\)；
  - \(W^S_l \leftarrow W^R_{l+1}\)（\(l<L\)），或 \(W^R_1\)（\(l=L\)）。
